# 客户保单对照表


---

人身保险公司（2024版）客户保单对照表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 客户保单对照表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 客户保单对照表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 客户保单对照表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 客户保单对照表 | 内部机构号 | 1、该保单承保机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 客户保单对照表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 客户保单对照表 | 客户编号 | 1、保险公司自行存储的唯一识别该客户的编号。关联数据项：个人客户信息表-客户编号/机构客户信息表-客户编号。 |  |
| 客户保单对照表 | 客户类别 | 1、客户分类。<br>2、枚举值：个人客户；个体工商户客户；法人客户；非法人组织客户。 |  |
| 客户保单对照表 | 客户属性 | 1、客户属性。<br>2、枚举值：投保人；被保人；受益人。 |  |
| 客户保单对照表 | 保单团个性质 | 1、按个人、集体等特征划分的保单分类。<br>2、枚举值：团体；个人；团个均可。 |  |
| 客户保单对照表 | 团体保单号 | 1、团体保单合同号，如为个人保单，填写默认值（000000）。关联数据项：团体保单表-团体保单号。 |  |
| 客户保单对照表 | 个人保单号 | 1、如为个人保单，填写个人保单合同号；如为团体保单，当客户属性为投保人时，填写默认值（000000），当客户属性为被保人或受益人时，填写相应被保人对应的分单号。关联数据项：个人保单表-个人保单号。 |  |
| 客户保单对照表 | 保单状态 | 1、保单截至报送期末的状态。其中，当客户在签单日期至保单生效日期之间撤单时，应报送“终止”。<br>2、枚举值：有效；中止；终止；未生效；其他。 |  |
| 客户保单对照表 | 实名认证通过标志 | 1、该个人客户是否通过实名认证。当“客户类别”为“个人客户”时，必填。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 客户保单对照表 | 实名认证方式 | 1、进行实名认证的方式。“实名认证通过标志”为“1”时，必填。<br>其中，对于城乡居民大病保险、长期护理保险等社会保险业务，若医保等政府部门已对被保险人个人信息进行前置身份核实，且保险公司从相关部门已获取被保险人个人信息的，填报前置认证；对于无法通过国家相关数据库进行查验，由保险公司、保险中介机构自主进行客户身份认证的，填报保险机构自主认证。填报中文描述。<br>2、枚举值：公安实名认证；前置认证；保险机构自主认证。 |  |
| 客户保单对照表 | 保单承保机构所在省 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 客户保单对照表 | 保单承保机构所在地市 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 客户保单对照表 | 保单承保机构所在区县 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 客户保单对照表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
