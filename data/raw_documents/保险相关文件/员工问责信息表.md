# 员工问责信息表


---

人身保险公司（2024版）员工问责信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 员工问责信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 员工问责信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工问责信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工问责信息表 | 所属内部机构号 | 1、员工当前所属内部机构所对应的内部机构号（最细粒度）。若截至问责日期，该员工已离职或退休，填报该员工离职或退休前所属内部机构号。关联数据项：分支机构信息表-内部机构号。 | 1、若员工所属分支机构发生变化，对于已报送的问责信息，暂不要求更新“所属内部机构号”信息。 |
| 员工问责信息表 | 所属机构名称 | 1、与所属内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 员工问责信息表 | 违法违规事实发生时所在机构号 | 1、被问责事件发生时该员工所在机构的内部机构号，填报最细粒度。如相关违法违规事实在一段期间内存续，填报事实起始日该员工所属内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 员工问责信息表 | 违法违规事实发生时所在机构名称 | 1、与“违法违规事实发生时所在机构号”相匹配的机构名称。关联数据项：分支机构信息表-机构名称。 |  |
| 员工问责信息表 | 员工编号 | 1、公司内部自行定义的员工编号，具有唯一性。一般由英文字母、数字、常见字符组成。关联数据项：员工信息表-员工编号。 |  |
| 员工问责信息表 | 员工姓名 | 1、员工身份证或护照的姓名。 |  |
| 员工问责信息表 | 董监高标志 | 1、判定是否属于保险业监督管理机构监管的董事、监事、高管范围，董监高人员范围参照《保险公司董事、监事和高级管理人员任职资格管理规定》等有关法律法规的最新规定认定。<br>以问责决定书上的时任职务为准，如问责决定书上无时任职务，按照如下方式处理：<br>（1）当相关问责针对某一时点的违法违规事实作出时，以违法违规时点的职务为准；<br>（2）当相关问责针对某一期间的违法违规事实作出时，以违法违规区间起始时点的职务为准；<br>（3）若均不涉及，则以问责日期的职务为准。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 员工问责信息表 | 问责编号 | 1、该条问责信息的唯一标识号，应在机构范围内唯一。 |  |
| 员工问责信息表 | 问责文号 | 1、填写内部问责文书对应的文号。如无，填报“不适用”。 | 1、若可保证所有内部问责均有文号，且相关文号在机构范围内具有唯一性，则问责文号与问责编号可为一致。 |
| 员工问责信息表 | 问责机构 | 1、填报问责机构的规范全称。 | 1、填报出具问责文书或作出问责决定的机构。 |
| 员工问责信息表 | 问责日期 | 1、填报问责文书的出具时间，或其他表明问责决定已作出的时间。 |  |
| 员工问责信息表 | 问责期起始日期 | 1、填报内部问责期间的开始日期。当相关问责方式或决定存在明确的起止时点时，必填。以禁止某员工在一定期间内晋升为例：公司作出问责决定的日期为问责日期，该员工禁止晋升期间的起止日期，如2021年1月1日至2021年12月31日，分别为此项问责所对应期间的开始日期与结束日期。 |  |
| 员工问责信息表 | 问责期结束日期 | 1、填报内部问责期间的终止日期。当相关问责方式或决定存在明确的起止时点时，必填。若相关问责覆盖终身，填报99990101。以禁止某员工在一定期间内晋升为例：公司作出问责决定的日期为问责日期，该员工禁止晋升期间的起止日期，如2021年1月1日至2021年12月31日，分别为此项问责所对应期间的开始日期与结束日期。 |  |
| 员工问责信息表 | 问责方式 | 1、问责方式。如涉及多个，需用半角英文分号分隔填列。<br>2、参照《业务代码表》“问责方式代码”，编号CD000063。 | 1、对于与枚举值表述不一致问责方式，可以结合内部问责方式的严重程度，据实映射，但相关映射逻辑需自行留存，以备检查。<br>2、若认为部分内部问责方式无合适取值可供映射，建议报送“其他”。 |
| 员工问责信息表 | 问责原因 | 1、填写问责文件列示的问责原因。主要内容为员工违法、违规、违纪的主要事实。 |  |
| 员工问责信息表 | 问责依据 | 1、填报作出此次问责的法律法规、内部规章的名称。 |  |
| 员工问责信息表 | 问责决定 | 1、填写问责文件列示的问责决定。 |  |
| 员工问责信息表 | 罚款金额 | 1、当“问责方式”包含“罚款”时，必填。填报该项问责对应的罚款金额。若截至采集日期，罚款金额尚未确定，可暂时报送“-1”，并待相关金额明确后更新报送。 | 1、对于罚款方式为分多个月进行薪资扣减的情况，如果相关金额在实际扣减绩效前已大致确定，“罚款金额”应直接按照已确定的罚款总金额报送，后续若发生变化，再另行更新报送。<br>2、如果问责方式填报“25扣减绩效工资”，则“罚款金额”字段是否填报空值。 |
| 员工问责信息表 | 以扣减薪资方式收取罚款标志 | 1、当“罚款金额”非空时，必填。用于判别人身保险公司是否以扣减薪资的方式收取罚款。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 员工问责信息表 | 资金流水编号 | 1、当“罚款金额”非空且“以扣减薪资方式收取罚款标志”为“0”时，必填。填报受问责人员缴纳罚款时，相关资金流水在人身保险公司内部的唯一标识号。如涉及多个，以英文半角分号分隔填列；若当月尚未生成，报送“未生成”。 |  |
| 员工问责信息表 | 外部处罚决定书文号 | 1、填报外部处罚的文号。当内部问责与外部处罚关联时，必填。关联数据项：员工处罚信息表-处罚文号。若外部处罚晚于内部问责发生，应在外部处罚发生后更新报送。 |  |
| 员工问责信息表 | 内部机构所在省 | 1、该员工所属内部机构注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工问责信息表 | 内部机构所在地市 | 1、该员工所属内部机构注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工问责信息表 | 内部机构所在区县 | 1、该员工所属内部机构注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工问责信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
