# 保单还款信息表


---

人身保险公司（2024版）保单还款信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 保单还款信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 保单还款信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 保单还款信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 保单还款信息表 | 内部机构号 | 1、该业务实际办理机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 保单还款信息表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 保单还款信息表 | 保单团个性质 | 1、按个人、集体等特征划分的保单分类。<br>2、枚举值：团体；个人；团个均可。 |  |
| 保单还款信息表 | 团体保单号 | 1、团体保单合同号，非团单填报000000。关联数据项：团体保单表-团体保单号。 |  |
| 保单还款信息表 | 个人保单号 | 1、个人保单合同号或团体保单分单号。关联数据项：个人保单表-个人保单号。 |  |
| 保单还款信息表 | 个单保险险种号码 | 1、该保单下险种在保险公司系统中的唯一标识（注意不是险种编码）。关联数据项：个人险种表-个单保险险种号码。若还款时无法对应至具体险种，报送“000000”。 |  |
| 保单还款信息表 | 险种编码 | 1、保险公司系统中对该险种的唯一标识。关联数据项：险种定义表-险种编码。若还款时无法对应至具体险种，报送“000000”。 |  |
| 保单还款信息表 | 批单号 | 1、当“内部划转标志”为“0”时，填报该笔保单还款或还垫对应的保全批单号。关联数据项：保全项目明细表-批单号。当“内部划转标志”为“1”时，填报人身保险公司内部自定义的代表本次还款或还垫的唯一业务编号。 |  |
| 保单还款信息表 | 偿还本金金额 | 1、本次偿还的本金金额。 | 1、建议与<保单借款信息表>中的“借款本金”相匹配。 |
| 保单还款信息表 | 偿还利息金额 | 1、本次偿还的利息金额。 |  |
| 保单还款信息表 | 还款日期 | 1、填报该笔还款的保全确认日期或内部资金划转日期。 |  |
| 保单还款信息表 | 内部划转标志 | 1、该笔还款是否涉及与个人客户的实际资金往来。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 保单还款信息表 | 内部划转方式 | 1、当“内部划转标志”为“1”时，必填。填报该笔还款内部划转的具体方式。<br>2、参照《业务代码表》“内部划转方式代码”，编号CD000038。 | 1、对于同时存在红利抵缴、满期抵缴或其他生存金抵缴等的情况，若可按照抵缴资金不同区分报送还款信息，优先考虑分别报送；若无法区分，则报送“混合抵缴”。<br>2、对于保单到期未还款系统自动滚存的情况，若保单贷款按照分别管理的方式（展期前后的借款在公司内部系统使用不同业务编号），展期前的借款若因自动滚存而视为清偿，在本表中报送一笔还款信息；同时，由于客户未实际偿还展期前的借款，建议视同内部划转，“内部划转方式”建议报送“其他”。 |
| 保单还款信息表 | 还款交易流水编号 | 1、该笔还款所对应的交易流水编号。关联数据项：交易流水表-交易流水编号。当“内部划转标志”为“1”时，可填报“不适用”；若当月尚未生成，报送“未生成”。 |  |
| 保单还款信息表 | 有效标志 | 1、标记此笔保单还款是否有效，默认为“1”。当该笔还款数据已报送且后续发生保全撤回时，更新为“0”。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 保单还款信息表 | 保单承保机构所在省 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 保单还款信息表 | 保单承保机构所在地市 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 保单还款信息表 | 保单承保机构所在区县 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 保单还款信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
