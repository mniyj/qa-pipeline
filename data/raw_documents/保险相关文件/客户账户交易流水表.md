# 客户账户交易流水表


---

人身保险公司（2024版）客户账户交易流水表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 客户账户交易流水表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 客户账户交易流水表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 客户账户交易流水表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 客户账户交易流水表 | 内部机构号 | 1、该项业务实际管理机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 客户账户交易流水表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 客户账户交易流水表 | 客户账户交易流水编号 | 1、人身保险公司赋予商业养老金业务每笔交易流水的唯一识别号，应在机构范围内唯一。 |  |
| 客户账户交易流水表 | 客户编号 | 1、个人客户在保险公司的唯一标识。关联数据项：个人客户信息表-客户编号。 |  |
| 客户账户交易流水表 | 交易账户账号 | 1、保险公司给个人客户分配的用于记录商业养老金产品交易和权益的信息户账号。关联数据项：客户账户信息表-交易账户账号。 |  |
| 客户账户交易流水表 | 产品代码 | 1、保险公司自行定义的商业养老金产品代码，应在机构范围内具有唯一性。关联数据项：商业养老金产品信息表-产品代码。 |  |
| 客户账户交易流水表 | 交易方向 | 1、致使客户持有份额增加的交易为“加保”，致使客户持有份额减少的交易为“减保”。<br>2、枚举值：加保；减保。 |  |
| 客户账户交易流水表 | 交易类型 | 1、该笔交易的具体类型。<br>2、枚举值：交费；领取；转换；解约；强增；强减；其他。 |  |
| 客户账户交易流水表 | 交易申请单位数量 | 1、客户提出的该笔交易申请（投保、减保等）所对应的单位数量。 |  |
| 客户账户交易流水表 | 交易申请金额 | 1、客户提出的该笔交易申请（投保、减保等）所对应的金额。 |  |
| 客户账户交易流水表 | 交易确认单位数量 | 1、交易申请单位数量中，确认交易成功的单位数量。 |  |
| 客户账户交易流水表 | 交易确认金额 | 1、交易确认的金额，原则上等于交易确认单位数量×交易确认时的产品单位价格。 |  |
| 客户账户交易流水表 | 交易确认日期 | 1、该笔交易的确认日期。 |  |
| 客户账户交易流水表 | 产品单位价格 | 1、交易确认时的产品单位价格。 |  |
| 客户账户交易流水表 | 单位价格日期 | 1、与“产品单位价格”相对应的单位价格日期，一般为“交易确认日期”的上一个交易日。 |  |
| 客户账户交易流水表 | 交易费用金额 | 1、包含手续费、解约费、账户管理费等该笔交易涉及的各类费用的总和。 |  |
| 客户账户交易流水表 | 认购期间利息 | 1、认购期间，产品资产存放于募集户产生的利息，对应至该笔交易的金额。 |  |
| 客户账户交易流水表 | 强制赎回标志 | 1、该笔交易是否为因解约等交易触发的强制赎回。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 客户账户交易流水表 | 强制赎回类型 | 1、当“强制赎回标志”为“1”时，必填。填报强制赎回的具体类型。其中，因解约或在产品未到期时赎回等情况导致的强制赎回为“违约赎回”；因产品清盘导致的强制赎回为“清盘赎回”；因流动性产品小份额带走及其他情况导致的强制赎回为“其他强制赎回”。<br>2、枚举值：违约赎回；清盘赎回；其他强制赎回。 |  |
| 客户账户交易流水表 | 份额强制调整标志 | 1、该笔交易是否为因保本补亏等非客户主动发起的交易而产生的份额变化。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 客户账户交易流水表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
