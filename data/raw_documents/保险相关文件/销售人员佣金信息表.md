# 销售人员佣金信息表


---

人身保险公司（2024版）销售人员佣金信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 销售人员佣金信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 销售人员佣金信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 销售人员佣金信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 销售人员佣金信息表 | 所属内部机构号 | 1、该销售人员实际管理机构的内部机构号（最细粒度）。关联数据项：分支机构信息表-内部机构号。 |  |
| 销售人员佣金信息表 | 所属机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 销售人员佣金信息表 | 所属销售条线 | 1、销售人员归属的销售条线类型。<br>2、枚举值：个险；团险；银保；其他。 |  |
| 销售人员佣金信息表 | 销售人员代码 | 1、保险公司分配给销售人员的工号或编号，应具有唯一性。 |  |
| 销售人员佣金信息表 | 销售人员姓名 | 1、销售人员的姓名。 |  |
| 销售人员佣金信息表 | 佣金发放年月 | 1、实际发放佣金的年月。例如：2023年1月25日支付佣金，佣金年月为202301。 |  |
| 销售人员佣金信息表 | 发放序号 | 1、报送期内给该销售人员发放佣金的序号，从1开始依次递增。 | 1、“报送期内”是指本表中每个“佣金发放年月”所对应的月度期间，从1开始编号即可。 |
| 销售人员佣金信息表 | 货币代码 | 1、发放佣金所使用的货币币种。<br>2、参照《业务代码表》“币种代码”，编号CD000009。 |  |
| 销售人员佣金信息表 | 基本工资 | 1、基本工资（底薪）。存在底薪的人员填报，不涉及填报0。 | 1、如果存在相关扣除金额属于基本工资的范围，应计入“基本工资”。 |
| 销售人员佣金信息表 | 首年度佣金金额 | 1、销售保单于首个保单年度的直接佣金，填报当月实际支付金额，不涉及填报0。 |  |
| 销售人员佣金信息表 | 续年度佣金金额 | 1、销售保单于续期/续保年度的直接佣金，填报当月实际支付金额，不涉及填报0。 |  |
| 销售人员佣金信息表 | 补助津贴 | 1、实际支付的各类补助和津贴类金额合计。 |  |
| 销售人员佣金信息表 | 奖金分红 | 1、实际支付的各类提奖、奖励、分红类金额合计。 |  |
| 销售人员佣金信息表 | 非现金奖励或福利 | 1、计税当月非现金奖励或福利的折现金额，包括实物奖励、保险福利等。 |  |
| 销售人员佣金信息表 | 扣除金额 | 1、品质扣款等各种扣费类金额合计，扣款时填报正值。如涉及暂扣款回补情况，可报送负值冲抵。 |  |
| 销售人员佣金信息表 | 佣金收入总额 | 1、每月实际支付的佣金收入总额（税前）。佣金收入总额=基本工资+首年度佣金金额+续年度佣金金额+补助津贴+奖金分红+非现金奖励或福利-扣除金额。 |  |
| 销售人员佣金信息表 | 佣金交易流水编号 | 1、发放该笔佣金对应的交易流水在人身保险公司内部的唯一标识号。关联数据项：交易流水表-交易流水编号。 |  |
| 销售人员佣金信息表 | 账户开立机构名称 | 1、该销售人员收取该笔佣金所使用账户（银行账户、第三方支付账户等）或数字货币钱包对应的开户机构名称，应与相关机构的工商注册信息保持一致。 |  |
| 销售人员佣金信息表 | 账户账号 | 1、该销售人员收取该笔佣金所使用的账户账号（银行账号、第三方支付账号等）或数字货币钱包的编号。 |  |
| 销售人员佣金信息表 | 账户户名 | 1、该销售人员收取该笔佣金所使用的账户（银行账户、第三方支付账户等）或数字货币钱包的名称。 |  |
| 销售人员佣金信息表 | 内部机构所在省 | 1、该销售人员实际管理机构所对应内部机构注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员佣金信息表 | 内部机构所在地市 | 1、该销售人员实际管理机构所对应内部机构注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员佣金信息表 | 内部机构所在区县 | 1、该销售人员实际管理机构所对应内部机构注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员佣金信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
