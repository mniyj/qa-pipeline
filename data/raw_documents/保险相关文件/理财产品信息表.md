| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 理财产品信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 理财产品信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 理财产品信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 理财产品信息表 | 投资账户代码 | 1、机构投资账户代码，应具有唯一性。关联数据项：投资账户信息表-投资账户代码。 |  |
| 理财产品信息表 | 投资账户名称 | 1、机构投资账户名称。 |  |
| 理财产品信息表 | 资产代码 | 1、机构自定义的资产代码，应在机构范围内具有唯一性。关联数据项：自主投资持仓表-资产代码。 |  |
| 理财产品信息表 | 产品代码 | 1、确权登记等有关机构配发或备案的代码。如有，必填；若无，填报“无”。 |  |
| 理财产品信息表 | 产品名称 | 1、填写确权登记等有关机构登记的产品名称，若无填写合同上的产品名称。 |  |
| 理财产品信息表 | 产品起始日期 | 1、产品初始运作日期。 |  |
| 理财产品信息表 | 产品预计终止日期 | 1、产品预计终止日期。默认值99990101。 |  |
| 理财产品信息表 | 发行方式 | 1、该产品是否公开发行。<br>2、枚举值：公开；不公开。 |  |
| 理财产品信息表 | 运行方式 | 1、理财产品的运行方式。<br>2、枚举值：开放式；封闭式。 |  |
| 理财产品信息表 | 产品发行人法定名称 | 1、指产品说明书中登载的发行人全称。 |  |
| 理财产品信息表 | 产品发行人证件类型 | 1、产品发行人证件类型，填报代码。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 理财产品信息表 | 产品发行人证件类型中文名称 | 1、产品发行人证件类型，填报中文名称。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 理财产品信息表 | 产品发行人证件号码 | 1、产品发行人证件号码。 |  |
| 理财产品信息表 | 产品发行人证件到期日 | 1、产品发行人证件到期日。 |  |
| 理财产品信息表 | 发行人LEI编码 | 1、填写发行人全球法人识别编码。 |  |
| 理财产品信息表 | 发行人所在地 | 1、产品发行人所属行政区划。除以下情况及其他可能存在的特例外，应填报省市县三级完整行政区划的名称：<br>（1）相关地区位于直辖市，如北京市海淀区；<br>（2）相关地区位于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县；<br>（3）相关地区位于未下设区县的市，如广东省东莞市、海南省儋州市；<br>（4）相关地区位于港澳台地区，如香港特别行政区。<br>如为除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 理财产品信息表 | 发行人类型 | 1、产品发行人的具体类型。<br>2、枚举值：银行；银行理财子公司。 |  |
| 理财产品信息表 | 核算方式 | 1、该产品是否净值型产品。<br>2、枚举值：净值型；非净值型。 |  |
| 理财产品信息表 | 产品类型 | 1、理财产品的分类。其中，固定收益类：投资债权类资产的比例不低于80%；权益类：投资股权类资产的比例不低于80%；商品及金融衍生品类：投资商品及金融衍生品的比例不低于80%；混合类：投资债权类资产、股权类资产、商品及金融衍生品且任一资产的投资比例未达到前三类标准。<br>2、枚举值：固定收益类；权益类；商品及金融衍生品类；混合类。 |  |
| 理财产品信息表 | 收益类型 | 1、按照是否保证本金与收益，对理财产品所做的分类。<br>2、枚举值：保本保收益类；保本浮动收益类；非保本浮动收益类；其他。 |  |
| 理财产品信息表 | 风险评级 | 1、根据《商业银行理财业务监督管理办法》第二十七条：理财产品风险评级结果应当以风险等级体现，由低到高至少包括一级至五级。<br>2、枚举值：一级；二级；三级；四级；五级。 |  |
| 理财产品信息表 | 资金投向 | 1、理财产品募集资金的具体投向。<br>2、枚举值：基础设施；工商企业；房地产；金融机构；证券类；其他。 |  |
| 理财产品信息表 | 结构化属性 | 1、产品是否分级。<br>2、枚举值：分级；非分级。 |  |
| 理财产品信息表 | 结构化级别 | 1、“结构化属性”为“分级”时必填。<br>2、枚举值：优先级；中间级；劣后级；无分级。 |  |
| 理财产品信息表 | 交易结构描述 | 1、交易结构文字描述。 |  |
| 理财产品信息表 | 成立以来年化投资收益率 | 1、填报截至采集日期，该理财产品自成立以来的年化投资收益率。 |  |
| 理财产品信息表 | 成本 | 1、初始投资总成本。 |  |
| 理财产品信息表 | 单位净值 | 1、“核算方式”为“净值型”时必填。单位：元/份。 |  |
| 理财产品信息表 | 市值 | 1、单位：元。 |  |
| 理财产品信息表 | 持有状态 | 1、理财产品的持有状态。<br>2、枚举值：持有；退出。 |  |
| 理财产品信息表 | 退出日期 | 1、“持有状态”为“退出”时必填。填写产品退出日期。 |  |
| 理财产品信息表 | 违约本息合计 | 1、截至本报送期末，发行人或融资主体发生违约本息合计。 |  |
| 理财产品信息表 | 违约本金余额 | 1、截至本报送期末，发行人或融资主体发生违约的本金。 |  |
| 理财产品信息表 | 违约利息余额 | 1、截至本报送期末，发行人或融资主体发生违约的利息。 |  |
| 理财产品信息表 | 违约发生日期 | 1、产品违约日期。 |  |
| 理财产品信息表 | 备注 | 1、填写其他需要报送的但是目前无法标准化的信息。 |  |
| 理财产品信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
