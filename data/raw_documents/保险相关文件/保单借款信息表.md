# 保单借款信息表


---

人身保险公司（2024版）保单借款信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 保单借款信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 保单借款信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 保单借款信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 保单借款信息表 | 内部机构号 | 1、该业务实际办理机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 保单借款信息表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 保单借款信息表 | 保单团个性质 | 1、按个人、集体等特征划分的保单分类。<br>2、枚举值：团体；个人；团个均可。 |  |
| 保单借款信息表 | 团体保单号 | 1、团体保单合同号，非团单填报000000。关联数据项：团体保单表-团体保单号。 |  |
| 保单借款信息表 | 个人保单号 | 1、个人保单合同号或团体保单分单号。关联数据项：个人保单表-个人保单号。 |  |
| 保单借款信息表 | 个单保险险种号码 | 1、该保单下险种在保险公司系统中的唯一标识（注意不是险种编码）。关联数据项：个人险种表-个单保险险种号码。 | 若无法到险种，报送000000。 |
| 保单借款信息表 | 险种编码 | 1、保险公司系统中对该险种的唯一标识。关联数据项：险种定义表-险种编码。 | 若无法到险种，报送000000。 |
| 保单借款信息表 | 自垫标志 | 1、该笔业务是否为保费自垫业务。填报“1”代表为保费自垫业务，填报“0”代表为保单借款业务。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 保单借款信息表 | 借款限额 | 1、当“自垫标志”为“0”时，必填。填报该保单险种可申请的最高借款额度。 | 1、报送保单险种可申请的最高借款额度，无需扣减已借款金额。 |
| 保单借款信息表 | 批单号 | 1、当“自垫标志”为“0”时，填报该笔保单借款对应的批单号。关联数据项：保全项目明细表-批单号。当“自垫标志”为“1”时，填报保险公司为该笔自垫业务定义的唯一编号。 | 1、对于到期未清偿自动展期的场景，若是保单借款，若展期无需客户另行提出保全申请，则可保留首次借款时的批单号；若是自垫业务，可结合公司对于自垫业务的管理情况报送最新的业务编号。 |
| 保单借款信息表 | 借款本金 | 1、当“自垫标志”为“0”时，填报该笔保单借款的本金金额；当“自垫标志”为“1”时，填报自垫保费金额。 | 1、对于保单贷款按照合并管理的方式（展期前后的借款在公司内部系统使用同一个业务编号）时，相关借款信息将随展期情况变化，借款本金或更新为展期后的本金。<br>2、对于保单贷款按照分别管理的方式（展期前后的借款在公司内部系统使用不同业务编号）时，两笔借款信息独立留存，展期前后的借款本金分别报送。 |
| 保单借款信息表 | 借款本金交易流水编号 | 1、保单借款本金对应的交易流水在人身保险公司内部的唯一标识号。关联数据项：交易流水表-交易流水编号。当未产生实际资金支付时（如“自垫标志”为“1”时），填写“不适用”；若当月尚未生成，报送“未生成”。 |  |
| 保单借款信息表 | 借款余额 | 1、填报截至采集日期，该笔保单借款或保费自垫业务待清偿的本息和。可按财务入账口径填报。 |  |
| 保单借款信息表 | 借款期限 | 1、当“自垫标志”为“0”时，必填。填报保单借款时约定的期限，以天为单位。例如，借款30天，填30。 | 1、对于保单贷款按照合并管理的方式（展期前后的借款在公司内部系统使用同一个业务编号）时，相关借款信息将随展期情况变化，借款期限更新为展期后的期限。<br>2、对于保单贷款按照分别管理的方式（展期前后的借款在公司内部系统使用不同业务编号）时，两笔借款信息独立留存，展期前后的借款期限分别报送。 |
| 保单借款信息表 | 借款日期 | 1、当“自垫标志”为“0”时，填报该笔保单借款审批通过的日期。当“自垫标志”为“1”时，填写保费自垫业务的发生日期。 |  |
| 保单借款信息表 | 起息日期 | 1、该笔保单借款或保费自垫业务开始计算利息的日期。 |  |
| 保单借款信息表 | 计息方式 | 1、借款计息方式。<br>2、枚举值：单利计息；复利计息。 |  |
| 保单借款信息表 | 利率类型 | 1、按照时间周期划分的利率类型。<br>2、枚举值：日利率；月利率；年利率；其他。 |  |
| 保单借款信息表 | 利率 | 1、借款或自垫时的利率。如借款周期内，该笔借款的计息利率发生变化，则截至报送期末的最新利率。 |  |
| 保单借款信息表 | 还清标志 | 1、“1”代表已还清，“0”代表未还清。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 保单借款信息表 | 还清日期 | 1、当“还清标志”为“1”时，必填。填报该笔保单借款或保费自垫业务的清偿日期。 | 1、填报客户以现金或转账等方式实际还清贷款金额的日期。如果借款到期后，公司直接将续借本金视作对已到期借款的偿还，本数据项可据实报送公司内部视同该笔借款已偿清的日期，并对应生成一条新的借款信息。<br>2、如保单各次借款在公司内部系统视作一笔借款管理（使用同一个业务编号），则可在此保单的借款余额均偿清后，再报送“还清日期”。 |
| 保单借款信息表 | 有效标志 | 1、标记此笔保单借款是否有效，默认为“1”。当该笔借款数据已报送且后续发生保全撤回时，更新为“0”。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 保单借款信息表 | 保单承保机构所在省 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 保单借款信息表 | 保单承保机构所在地市 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 保单借款信息表 | 保单承保机构所在区县 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 保单借款信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
