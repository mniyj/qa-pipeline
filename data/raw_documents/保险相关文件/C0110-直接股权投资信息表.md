# C0110-直接股权投资信息表


---

## C0110-直接股权投资信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 直接股权投资信息表 | 投资账户名称 | 机构投资账户名称，应具有唯一标识。 | 1、填报机构投资账户名称，应具有唯一标识。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 直接股权投资信息表 | 投资账户代码 | 机构投资账户代码，应具有唯一标识。 | 1、填报机构投资账户代码，应具有唯一标识。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 直接股权投资信息表 | 资产名称 | 填写确权登记等有关机构登记的资产名称，若无填写合同上的资产名称。 | 1、填报确权登记等有关机构登记的资产名称，若无填报合同上的资产名称。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 直接股权投资信息表 | 资产代码 | 填写确权登记等有关机构登记的资产代码，若无填写机构自定义代码。 | 1、填报确权登记等有关机构登记的资产代码，若无填报机构自定义代码。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 直接股权投资信息表 | 是否属于重大股权投资 | 重大股权投资指对拟投资企业实施控制的投资行为。参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、重大股权投资指对拟投资企业实施控制的投资行为。<br>2、参照《业务代码表》中的“是否判断代码”，填报代码。 |
| 直接股权投资信息表 | 是否属于关联交易 | 投资前与标的企业是否存在关联方关系。参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、投资前与标的企业是否存在关联方关系。<br>2、参照《业务代码表》中的“是否判断代码”，填报代码。 |
| 直接股权投资信息表 | 是否派驻人员 | 是否选派董事、监事或重要岗位人员。参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、是否选派董事、监事或重要岗位人员。<br>2、参照《业务代码表》中的“是否判断代码”，填报代码。 |
| 直接股权投资信息表 | 派驻人员情况 | 填写派出的股东代表、董事、监事、高管的姓名及岗位。 | 填报派出的股东代表、董事、监事、高管的姓名及岗位。 |
| 直接股权投资信息表 | 标的企业法定名称 | 名称应与营业执照上所使用的名称完全一致。如暂未取得营业执照，机构可自行定义。 | 1、填报名称应与营业执照上所使用的名称完全一致。如暂未取得营业执照，机构可自行定义。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 直接股权投资信息表 | 标的企业证件类型 | 标的企业证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报标的企业证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。 |
| 直接股权投资信息表 | 标的企业证件号码 | 标的企业证件号码。 | 1、填报标的企业证件号码。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 直接股权投资信息表 | 标的企业证件到期日 | 标的企业证件到期日。 | 1、填报标的企业证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 直接股权投资信息表 | 标的企业LEI编码 | 填写标的企业全球法人识别编码。 | 1、填报标的企业全球法人识别编码。<br>2、LEI是按照国际标准化组织ISO 17442标准为全球法人分配的唯一识别编码，LEI编码是由20位数字和字母组成的唯一编码。我国LEI编码包括前缀码部分、预留位部分、机构特定部分和校验位四部分。 |
| 直接股权投资信息表 | 境内外标识 | 填报境内外标识。参照《业务代码表》中的“境内外标识代码”，填报代码。 | 1、填报境内外标识。<br>2、参照《业务代码表》中的“境内外标识代码”，填报代码。 |
| 直接股权投资信息表 | 标的企业所属地区 | 参照《业务代码表》中的“行政区划代码”，填报代码。 | 参照《业务代码表》中的“行政区划代码”，填报代码。 |
| 直接股权投资信息表 | 标的企业控股股东性质 | 枚举值为“中央国有企业，地方国有企业，民营企业，外资企业，公众公司，其他”。 | 枚举值为“中央国有企业，地方国有企业，民营企业，外资企业，公众公司，其他”。 |
| 直接股权投资信息表 | 标的企业类型 | 枚举值为“保险类企业；非保险类金融企业；能源企业；资源企业；保险业务相关企业；其他”。 | 枚举值为“保险类企业；非保险类金融企业；能源企业；资源企业；保险业务相关企业；其他”。 |
| 直接股权投资信息表 | 标的企业所属行业 | 参照《业务代码表》中的“行业类型代码”，填报代码。 | 参照《业务代码表》中的“行业类型代码”，填报代码。 |
| 直接股权投资信息表 | 政策标签 | 参照《业务代码表》中的“政策标签代码”，填报代码。可多选，如存在多个标签，以“;”隔开。如为其他，需在备注里描述。 | 1、参照《业务代码表》中的“政策标签代码”，填报代码。<br>2、可多选，如存在多个标签，以英文分号“;”分隔。如为其他，需在备注里描述。 |
| 直接股权投资信息表 | 总资产 | 若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。 |
| 直接股权投资信息表 | 净资产 | 若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。 |
| 直接股权投资信息表 | 累计营业收入 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。<br>2、累计营业收入指投资以来累计收入 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。<br>3、累计营业收入指投资以来累计收入. |
| 直接股权投资信息表 | 累计净利润 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。<br>2、累计净利润指投资以来累计净利润 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。<br>3、累计净利润指投资以来累计净利润 |
| 直接股权投资信息表 | 初始投资日期 | 以投资合同中初始投资日期为准。如合同未约定初始投资日期，以首笔出资支付日期为准。 | 1、以投资合同中初始投资日期为准。如合同未约定初始投资日期，以首笔出资支付日期为准。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 直接股权投资信息表 | 标的企业估值 | 投资时点标的企业估值。若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、填报投资时点标的企业估值。<br>2、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>3、单位：元。 |
| 直接股权投资信息表 | 初始持股占比 | 初始持股占比，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。 | 1、填报初始持股占比。<br>2、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。 |
| 直接股权投资信息表 | 控股方式 | 枚举值为“绝对控股，相对控股，协议控股，其他，非控股”。 | 枚举值为“绝对控股，相对控股，协议控股，其他，非控股”。 |
| 直接股权投资信息表 | 投资币种 | 参照《业务代码表》中的“币种代码”，填报代码。 | 参照《业务代码表》中的“币种代码”，填报代码。 |
| 直接股权投资信息表 | 初始投资金额 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。<br>2、资产在投资后进行部分处置，初始投资金额不调整。<br>3、分期投资资产，初始投资按整体款项计量。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。<br>3、资产在投资后进行部分处置，初始投资金额不调整。<br>4、分期投资资产，初始投资按整体款项计量。 |
| 直接股权投资信息表 | 累计投资金额 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。<br>2、资产在投资后进行部分处置，累计投资金额为累计投资本金。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。<br>3、资产在投资后进行部分处置，累计投资金额为累计投资本金。 |
| 直接股权投资信息表 | 期末投资账面余额 | 若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。 |
| 直接股权投资信息表 | 期末投资账面价值 | 若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。 |
| 直接股权投资信息表 | 期末最新持股占比 | 数据填报口径为截至报送日上月月末数据，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。 | 1、数据填报口径为截至报送日上月月末数据。<br>2、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。 |
| 直接股权投资信息表 | 投资以来累计实现收益 | 数据填报口径为截至报送日上月月末数据，单位：元。 | 1、数据填报口径为截至报送日上月月末数据。<br>2、单位：元。 |
| 直接股权投资信息表 | 当年收益率 | 当年以来的收益率，需年化。填数字，不填百分比，最少保留四位小数，比如12.34%填写为0.1234。默认值99999。 | 1、填报当年以来的收益率，需年化。<br>2、填数字，不填百分比，精度为六位小数。如3.1234%填写为0.031234。默认值“99999”。 |
| 直接股权投资信息表 | 累计收益率 | 投资以来的累计收益率，填数字，不填百分比，最少保留四位小数，比如12.34%填写为0.1234。默认值99999。 | 1、填报投资以来的累计收益率。<br>2、填数字，不填百分比，精度为六位小数。如3.1234%填写为0.031234。默认值“99999”。 |
| 直接股权投资信息表 | 是否退出 | 参照《业务代码表》中的“是否判断代码”，填报代码。 | 参照《业务代码表》中的“是否判断代码”，填报代码。 |
| 直接股权投资信息表 | 退出日期 | “是否退出”为“是”时必填。填写退出日期。 | 1、按照YYYYMMDD格式填报退出日期。<br>2、“是否退出”为“是”时必填。 |
| 直接股权投资信息表 | 退出方式 | “是否退出”为“是”时必填。填写退出方式。包括：回购；清算；转让第三方；IPO；并购；其他。 | 1、填报退出方式。<br>2、按照枚举值“回购；清算；转让第三方；IPO；并购；其他”填报中文名称。<br>3、“是否退出”为“是”时必填。 |
| 直接股权投资信息表 | 备注 | 填写其他需要报送的但是目前无法标准化的信息。 | 填报其他需要报送的但是目前无法标准化的信息。 |
