# 个人保单表


---

人身保险公司（2024版）个人保单表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 个人保单表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 个人保单表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 个人保单表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 个人保单表 | 内部机构号 | 1、该保单承保机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 | 1、对于挂在向统信报备的虚拟机构上的保单，如果“分支机构信息表”未报送相关虚拟机构信息，建议考虑向上映射，同步建议报备说明。 |
| 个人保单表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 个人保单表 | 投保单号 | 1、团体保单或个人保单的投保单号。关联数据项：保单险种核保信息表-投保单号。 |  |
| 个人保单表 | 投保人客户编号 | 1、投保人客户在保险公司的唯一标识，需要保险公司提前对客户数据进行合并后报送。关联数据项：个人客户信息表-客户编号/机构客户信息表-客户编号。 |  |
| 个人保单表 | 投保单申请日期 | 1、客户填写投保单的日期。通常是投保单上客户签字日期，如果是电子投保单，则为投保单填写完成后的提交日期。 |  |
| 个人保单表 | 保单团个性质 | 1、按个人、集体等特征划分的保单分类。<br>2、枚举值：团体；个人；团个均可。 |  |
| 个人保单表 | 团体保单号 | 1、团体保单合同号，非团单填报000000。 |  |
| 个人保单表 | 个人保单号 | 1、个人保单合同号或团体保单分单号。 |  |
| 个人保单表 | 续保保单标志 | 1、本保单是否为过往保单的续保保单。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、对于团体保单，可仅按团单粒度识别续保标志，团单下的分单“续保保单标志”可报送“0”。<br>2、个人短期险非保证续保业务可按业务实质报送。若相关保单从条款设计及实际管理角度而言，均不适用续保约定，可据实报送“0”。<br>3、对于重新投保和转保的情况（例如无保证续保条款的保单到期后签新单或新老产品承接等），如果无等待期，建议报送“1”，否则不视作续保。 |
| 个人保单表 | 被续保保单编号 | 1、当“续保保单标志”为“1”时，填报被续保保单的个人保单号。 | 1、当续保产品以附加险形式体现时，续保产品保单号与主险相同，并且对于多个续保险种在同一主险下，导致多续保险种共用同一保单号的情况，报送原保单号。 |
| 个人保单表 | 保险产品组合销售名称 | 1、报送该保单对应保险产品组合的销售名称，即保险产品组合面向保险消费者的销售名称。 |  |
| 个人保单表 | 政保合作业务标志 | 1、该保单是否为政保合作业务。<br>考虑部分场景下，对于政保合作业务，保险公司可获取的信息较为有限，增设该标志，用于判别该保单是否政保合作业务保单。本规范所称政保合作业务指各级政府部门主导、保险机构参与，有财政支持或其他政策扶持，关系到经济民生并在社会上具有较大影响的保险项目。当该标志为“1”时，各公司仍应按照可得信息尽可能报送数据。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 个人保单表 | 保单回执签收标志 | 1、结合有关监管要求与保险公司业务管理实际情况，该保单是否要求客户签收保单回执。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、若在实际业务中部分保单不要求客户签收保单回执的（例如电子保单、团单分单），可据实报送“0”。<br>2、对于因团单增人而产生的新分单，若不存在逐一签收保单回执的要求，报送“0”。 |
| 个人保单表 | 保单回执客户签收日期 | 1、当“保单回执签收标志”为“1”时，必填。填报客户签收保险合同回执的日期。若截至采集日期，客户尚未签收回执，报送99990101。 | 1、当“保单回执签收标志”报送“0”时，“保单回执客户签收日期”可为空。 |
| 个人保单表 | 保单状态 | 1、保单截至报送期末的状态。其中，当客户在签单日期至保单生效日期之间撤单时，应报送“终止”。<br>2、枚举值：有效；中止；终止；未生效；其他。 |  |
| 个人保单表 | 保单形式 | 1、保单合同的形式。<br>2、枚举值：纸质保单；电子保单；纸质保单+电子保单。 | 1、对于团单业务，填报分单合同形式。 |
| 个人保单表 | 承保地区 | 1、该保单的承保地区。除以下情况及其他可能存在的特例外，应填报省市县三级完整行政区划的名称：<br>（1）承保地区位于直辖市，如北京市海淀区；<br>（2）承保地区位于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县；<br>（3）承保地区位于未下设区县的市，如广东省东莞市、海南省儋州市；<br>（4）承保地区位于港澳台地区，如香港特别行政区。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 个人保单表 | 销售渠道 | 1、保险经营机构向客户提供保险产品和服务的途径。<br>2、参照《业务代码表》“销售渠道类型代码”，编号CD000003。 |  |
| 个人保单表 | 中介机构代码 | 1、保险公司分配给本保单中介机构的唯一标识号，应与《中介机构信息表》中的“中介机构代码”一致。如涉及多个，以英文半角分号分隔填列。 |  |
| 个人保单表 | 中介机构名称 | 1、与中介机构代码相匹配的名称，应与工商注册信息所使用的名称完全一致。如涉及多个，以英文半角分号分隔填列。 |  |
| 个人保单表 | 交费间隔 | 1、保险合同中约定的保费缴纳周期。说明如下：<br>（1）如该保单下多个险种的交费间隔不同，以主险为准；<br>（2）如该保单下存在多个主险，以保险期间最长的主险为准；<br>（3）如该保单下存在多个保险期间相同的主险，以交费频次高的主险为准。<br>2、枚举值：趸交；日交；月交；季交；半年交；年交；不定期交费；交至固定年龄；其他。 |  |
| 个人保单表 | 交费方式 | 1、保险合同中约定的保费缴纳方式，如该保单下多个险种的交费方式不同，以主险为准。<br>2、参照《业务代码表》“收付款方式代码”，编号CD000010。 | 1、对于约定自行交费，客户可能选择微信、支付宝、网银转账等方式，则报送客户最近一次实际交费的交费方式。 |
| 个人保单表 | 签单日期 | 1、合同签订的日期，即承保日期。 |  |
| 个人保单表 | 保单生效日期 | 1、依法成立的保险合同，根据法律规定或合同约定在保险合同当事人之间产生法律约束力的日期。 |  |
| 个人保单表 | 货币代码 | 1、保费及保额的计价货币代码。<br>2、参照《业务代码表》“币种代码”，编号CD000009。 |  |
| 个人保单表 | 保费 | 1、投保人为取得保险保障，按保险合同约定向保险人支付的费用，即保单下各险种的保费和。趸缴保单，填报趸缴保费；期缴保单，填报当期保费；不定期交费保单，仅填报首期保费。如保全引起保费变化，据实报送，但保费不随保单状态、缴费状态改变。部分政保合作业务的保费若无法按照个人保单或团单分单的粒度拆分，填报“-1”。 | 1、当保单下部分险种终止致使期缴保费减少时，报送截至采集日期的最新期缴保费金额。<br>2、当整单终止时，本数据项保留原保费，无需清零。<br>3、如保单信息在一个报送周期内发生多次变化，需报送历次变化轨迹的多条数据。 |
| 个人保单表 | 保额 | 1、保单上记录的所有未终止险种基本保额之和。部分政保合作业务如不适用，填报“-1”。 | 1、对于某保单下部分险种有效，部分险种已终止的情况，报送有效险种的保额。<br>2、对于整单退保或整单满期终止的保单，报送对应时点记录的最新保额。 |
| 个人保单表 | 累计保费 | 1、该保单已缴纳并核销的保费合计金额，包含保全补费，不包含保全退费、退保金。部分政保合作业务的保费若无法按照个人保单或团单分单的粒度拆分，填报“-1”。 | 1、保全补费是指因保全操作（如增加保险金额）而补充缴纳的保费。 |
| 个人保单表 | 现金价值 | 1、该保单的现金价值（不含账户价值），等于《个人险种表》中该保单下全部险种现金价值的加总金额。 | 1、对于因现金价值未领取而产生的睡眠保单，此处不可报0。<br>2、保单年度期间，若因客户申请发生现金价值试算，也可在试算当期以试算结果更新该信息。 |
| 个人保单表 | 首期交费日期 | 1、保费的应缴起始日期，如该保单下多个险种的首期缴费日期不同，以主险为准；若多个主险的首期交费日期不同，以其中的最早日期为准。 | 1、首期若无应缴费日期，可报送客户打款日期。 |
| 个人保单表 | 交至日期 | 1、下次应交保费日期，如该保单下的多个险种的交至日期不同，以主险为准；如该保单下有多个主险，填报与“交费间隔”相对应的交至日期；如果是最后一次交费，则取本次的应交费日期。部分政保业务如不适用，可填报“99990101”。 |  |
| 个人保单表 | 保单满期日期 | 1、保单满期日期。请注意：此日期须按照24时报送。假设某10年期保单的生效日期为XX01-01-01（0时起生效），满期日期为XX10-12-31（24时终止），则此处应报送XX101231，而非XX110101。对于终身险，默认为99990101。 |  |
| 个人保单表 | 保单终止日期 | 1、当“保单状态”为“终止”时，必填。填报保险人所承担保险责任的结束时间。请注意：此日期须按照24时报送。也即，若此处报送20250808，则表示该保单在2025年8月8日24时终止。 | 1、对于客户退保导致的保单终止，应填报客户实际与公司约定解除合同的日期，不考虑保险责任结束日期因素。 |
| 个人保单表 | 保单中止日期 | 1、指保单效力暂停的时间，承保为空。如保单不存在效力中止，该数据项为空；如保单当前或以前存在中止状态，报送保单最近一次的中止日期。 |  |
| 个人保单表 | 保单效力恢复日期 | 1、保险合同中止后一定时间内，由投保人申请，经保险公司同意，投保人补缴保险费及利息后，保险合同效力恢复的日期。如保单不存在效力中止，该数据项为空；如保单当前为中止状态，该数据项为空；如保单效力已恢复，填报最近一次的复效日期。 |  |
| 个人保单表 | 保单终止原因 | 1、导致保险合同当事人的权利义务关系结束的原因。当“保单状态”为“终止”时，必填。填报与“保单终止日期”相对应的终止原因，如保单下多险种终止原因不同，填报主险终止原因。<br>2、参照《业务代码表》“保单/险种终止原因代码”，编号CD000048。 |  |
| 个人保单表 | 保单中止原因 | 1、导致保险合同当事人的权利义务关系暂时中止的原因。当“保单中止日期”非空时，必填。填报与“保单中止日期”相匹配的中止原因。 |  |
| 个人保单表 | 保单承保机构所在省 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 个人保单表 | 保单承保机构所在地市 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 个人保单表 | 保单承保机构所在区县 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 个人保单表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
