# 红利分配表


---

人身保险公司（2024版）红利分配表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 红利分配表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 红利分配表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 红利分配表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 红利分配表 | 内部机构号 | 1、该业务实际办理机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 红利分配表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 红利分配表 | 保单团个性质 | 1、按个人、集体等特征划分的保单分类。<br>2、枚举值：团体；个人；团个均可。 |  |
| 红利分配表 | 团体保单号 | 1、团体保单合同号，非团单填报000000。关联数据项：团体保单表-团体保单号。 |  |
| 红利分配表 | 团单保险险种号码 | 1、该保单下险种在保险公司系统中的唯一标识（注意不是险种编码）。团单必填，非团单填写默认值（000000）。关联数据项：团体险种表-团单保险险种号码。 |  |
| 红利分配表 | 个人保单号 | 1、个人保单合同号或团体保单分单号。关联数据项：个人保单表-个人保单号。 |  |
| 红利分配表 | 个单保险险种号码 | 1、该保单下险种在保险公司系统中的唯一标识（注意不是险种编码）。关联数据项：个人险种表-个单保险险种号码。 |  |
| 红利分配表 | 险种编码 | 1、保险公司系统中对该险种的唯一标识。关联数据项：险种定义表-险种编码。 |  |
| 红利分配表 | 红利年度 | 1、保单应分红的红利年度。 | 1、按照自然年度口径报送。 |
| 红利分配表 | 红利类型 | 1、分红保险的红利类型。<br>2、枚举值：现金红利；增额红利。 | 1、现金红利指以现金形式支付的一类红利，增额红利为红利用于增加保额的一类红利。 |
| 红利分配表 | 当期红利派发金额 | 1、保险公司在本红利年度派发的红利金额，单位元（人民币）。如为现金红利，填报现金金额；如为增额红利，填报本期因分红增加的保险金额。 |  |
| 红利分配表 | 当期红利派发日期 | 1、保险公司派发当期红利的日期。 |  |
| 红利分配表 | 红利领取方式 | 1、截至本次分配时，客户指定的保单红利领取方式。<br>2、枚举值：现金领取；累积生息；抵交保费；转投新保；增额交清；划转万能、投连等保险账户；偿还保单贷款；其他。 | 1、对于增额红利统一报送“其他”。 |
| 红利分配表 | 有效标志 | 1、标记此笔分红数据是否有效，默认为“1”。当此分红数据已报送且后续发生红利撤回时，将此条数据的有效标志更新为“0”。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、若已报送的分红信息因理赔导致保单终止从而不再发放，应将该标志更新为“0”。 |
| 红利分配表 | 保单承保机构所在省 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 红利分配表 | 保单承保机构所在地市 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 红利分配表 | 保单承保机构所在区县 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 红利分配表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
