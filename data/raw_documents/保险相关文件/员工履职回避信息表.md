# 员工履职回避信息表


---

人身保险公司（2024版）员工履职回避信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 员工履职回避信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 员工履职回避信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工履职回避信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工履职回避信息表 | 所属内部机构号 | 1、员工所属内部机构所对应的内部机构号（最细粒度）。关联数据项：分支机构信息表-内部机构号。 |  |
| 员工履职回避信息表 | 所属机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 员工履职回避信息表 | 员工编号 | 1、公司内部自行定义的员工编号，具有唯一性。一般由英文字母、数字、常见字符组成。关联数据项：员工信息表-员工编号。 |  |
| 员工履职回避信息表 | 员工姓名 | 1、员工身份证或护照的姓名。 |  |
| 员工履职回避信息表 | 董监高标志 | 1、表示应执行履职回避要求时，该员工在该内部机构是否属于保险业监督管理机构监管的董事、监事、高管范围。董监高人员范围参照《保险公司董事、监事和高级管理人员任职资格管理规定》等有关法律法规的最新规定认定。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 员工履职回避信息表 | 履职回避编号 | 1、公司内部自行定义的履职回避事项编号，应在机构范围内具有唯一性。 |  |
| 员工履职回避信息表 | 执行履职回避状态 | 1、根据《银行保险机构员工履职回避工作的指导意见》及其具体执行要求所确认的履职回避状态或结果。其中，若截至采集日期，既往已报送的“执行履职回避状态”为“未执行”、“豁免执行”或“其他”的事项已在本期完成执行，保险公司应将相关数据的“执行履职回避状态”更新为“已执行”。<br>2、枚举值：未执行；豁免执行；已执行；其他。 |  |
| 员工履职回避信息表 | 豁免期限 | 1、当“执行履职回避状态”为“豁免执行”时，必填。填报豁免执行的截止时间。 |  |
| 员工履职回避信息表 | 履职回避事项 | 1、简要说明履职回避的原因或具体事项，如“本人成长地回避”、“7年任职回避”等，若未来监管要求发生变化，应以最新要求为准报送数据。 |  |
| 员工履职回避信息表 | 履职回避说明 | 1、简要说明履职回避具体事项及相关执行情况（包括但不限于未执行或豁免执行的原因、已执行情况及其他有关信息）。例如，XXXX年XX月XX日至XXXX年XX月XX日在某地学习（或工作），XXXX年XX月XX日至XXXX年XX月XX日在该地担任某职务，应执行“本人成长地回避”，因XX原因尚未（或豁免）执行履职回避要求。待履行相关要求后，可补充说明情况，如已于XXXX年XX月XX日调整至某地任职。 |  |
| 员工履职回避信息表 | 内部机构所在省 | 1、该员工所属内部机构注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工履职回避信息表 | 内部机构所在地市 | 1、该员工所属内部机构注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工履职回避信息表 | 内部机构所在区县 | 1、该员工所属内部机构注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工履职回避信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
