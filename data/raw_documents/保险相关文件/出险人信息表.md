# 出险人信息表


---

人身保险公司（2024版）出险人信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 出险人信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 出险人信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 出险人信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 出险人信息表 | 内部机构号 | 1、该赔案受理机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 出险人信息表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 出险人信息表 | 赔案号 | 1、保险公司记录的该案件的赔案号，应具有唯一性。关联数据项：理赔案件信息表-赔案号。 |  |
| 出险人信息表 | 政保合作业务标志 | 1、考虑部分场景下，对于政保合作业务，保险公司可获取的信息较为有限，增设该标志，用于判别该赔案是否政保合作业务保单赔案。本规范所称政保合作业务指各级政府部门主导、保险机构参与，有财政支持或其他政策扶持，关系到经济民生并在社会上具有较大影响的保险项目。当该标志为“1”时，各公司仍应按照可得信息尽可能报送数据。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 出险人信息表 | 出险人客户编号 | 1、出险人在保险公司的唯一客户标识。关联数据项：个人客户信息表-客户编号。 |  |
| 出险人信息表 | 出险人姓名 | 1、出险人的姓名。隐私，人身保险公司变形。 |  |
| 出险人信息表 | 出险人性别 | 1、出险人的性别。<br>2、枚举值为：01；02；03；04。 |  |
| 出险人信息表 | 出险人出生年月 | 1、出险人的出生年月。 |  |
| 出险人信息表 | 出险人证件类型 | 1、出险人证件类型，填报代码。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 出险人信息表 | 出险人证件类型中文名称 | 1、出险人证件类型，填报中文名称。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 出险人信息表 | 出险人证件号码 | 1、与证件类型相匹配的出险人证件号码。隐私，人身保险公司变形。 |  |
| 出险人信息表 | 死亡标志 | 1、出险人是否已死亡，以形成理赔结论时的死亡状态为准。“政保合作业务标志”为“0”时，必填。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 出险人信息表 | 死亡日期 | 1、出险人的死亡日期，当死亡标志为“1”时，必填。 |  |
| 出险人信息表 | 死亡原因 | 1、出险人的死亡原因。当死亡标志为“1”时，必填。<br>2、枚举值：疾病；意外；自杀；猝死；其他。 |  |
| 出险人信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
