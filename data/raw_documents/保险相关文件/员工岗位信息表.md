# 员工岗位信息表


---

人身保险公司（2024版）员工岗位信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 员工岗位信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 员工岗位信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工岗位信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工岗位信息表 | 所属内部机构号 | 1、员工所属内部机构所对应的内部机构号（最细粒度）。关联数据项：分支机构信息表-内部机构号。 |  |
| 员工岗位信息表 | 所属机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 员工岗位信息表 | 员工编号 | 1、公司内部自行定义的员工编号，具有唯一性。一般由英文字母、数字、常见字符组成。关联数据项：员工信息表-员工编号。 |  |
| 员工岗位信息表 | 员工姓名 | 1、员工身份证或护照的姓名。 |  |
| 员工岗位信息表 | 董监高岗位标志 | 1、表示是否属于保险业监督管理机构监管的董事、监事、高管范围。董监高人员范围参照《保险公司董事、监事和高级管理人员任职资格管理规定》等有关法律法规的最新规定认定。<br>该标志以岗位为单位认定，即当某个员工在同一机构范围内兼任多个岗位时，仅董监高相关岗位报送“1”。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 员工岗位信息表 | 重要岗位标志 | 1、该岗位是否本机构重要岗位。其中，重要岗位的定义参照《中国银保监会关于银行保险机构员工履职回避工作的指导意见》等相关规定执行。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 员工岗位信息表 | 岗位编码 | 1、保险公司对各岗位的唯一编码。 |  |
| 员工岗位信息表 | 岗位名称 | 1、保险公司对内部各岗位的命名。 |  |
| 员工岗位信息表 | 上岗日期 | 1、该员工开始履行该岗位职责的日期。 |  |
| 员工岗位信息表 | 离岗日期 | 1、该员工终止履行该岗位职责的日期，若仍在岗则填默认值99990101。 | 1、对于干部离职、退休前下发免职发文的，优先按照“免职日期”报送。 |
| 员工岗位信息表 | 内部机构所在省 | 1、该员工所属内部机构注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工岗位信息表 | 内部机构所在地市 | 1、该员工所属内部机构注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工岗位信息表 | 内部机构所在区县 | 1、该员工所属内部机构注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工岗位信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
