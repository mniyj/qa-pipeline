# A0202-股权信息表


---

## A0202-股权信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 股权信息表 | 股东编号 | 公司内部自行定义的股东编号，应具有唯一性。 | 1、填报公司内部自行定义的股东编号，应具有唯一性。<br>2、“股东编码”不可填报证件号码或集团EAST规范默认值或其他无效数据。<br>3、所有报送期次的数据中，同一股东的股东编号和股东法定名称应保持一一对应。 |
| 股权信息表 | 股东法定名称 | 对自然人股东，为股东姓名；对法人股东，为股东经有关部门批准正式使用的机构全称。 | 1、填报股东的名称。<br>2、对自然人股东，填报股东姓名；对法人股东，填报经有关部门批准正式使用的机构全称。<br>2、所有报送期次的数据中，同一股东的股东编号和股东法定名称应保持一一对应。 |
| 股权信息表 | 股东证件类型 | 对自然人，优先选填股东居民身份证；对机构，优先选填统一社会信用代码。参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报股东的证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。<br>3、需与“股东证件号码”对应类型一致。 |
| 股权信息表 | 股东证件号码 | 填写有效证件号码。若为自然人证件号码，隐私，保险集团（控股）公司变形。 | 1、填报股东有效证件号码。<br>2、对自然人股东，填写自然人证件号码，若股东为中华人民共和国公民，优先填居民身份证；对境内法人股东，填写统一社会信用代码，境外法人股东填写企业注册码、税务号等有效代码。<br>3、若为自然人证件号码，按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 股权信息表 | 股东证件到期日 | 股东证件到期日。 | 1、填报股东证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 股权信息表 | 股东类型 | 按《保险公司股权管理办法》的股东分类填报。参照《业务代码表》中的“股东类型代码”，填报代码。 | 1、根据《保险公司股权管理办法》规定的股东分类填报。<br>2、参照《业务代码表》中的“股东类型代码”，填报代码。 |
| 股权信息表 | 股东类别 | 按照股东自然人或机构属性。参照《业务代码表》中的“股东类别代码”，填报代码。 | 1、按照股东自然人或机构属性填报。<br>2、参照《业务代码表》中的“股东类别代码”，填报代码。 |
| 股权信息表 | 股东国别 | 参照《业务代码表》中的“国家地区”，填报代码。 | 参照《业务代码表》中的“国家地区”，填报代码。 |
| 股权信息表 | LEI编码 | 股东机构的全球法人机构识别编码，LEI是按照国际标准化组织ISO 17442标准为全球法人分配的唯一识别编码，LEI编码是由20位数字和字母组成的唯一编码。我国LEI编码包括前缀码部分、预留位部分、机构特定部分和校验位四部分。 | 1、填报法人股东的全球法人机构识别编码，自然人股东不填报内容。<br>2、LEI是按照国际标准化组织ISO 17442标准为全球法人分配的唯一识别编码，LEI编码是由20位数字和字母组成的唯一编码。我国LEI编码包括前缀码部分、预留位部分、机构特定部分和校验位四部分。 |
| 股权信息表 | 行业类型 | 股东为非自然人时，必填。按股东所从事的生产经营活动或其他社会经济活动的性质进行行业分类，参照《业务代码表》中的“行业类型代码”，填报代码。 | 1、按股东所从事的生产经营活动或其他社会经济活动的性质进行行业分类，法人股东必填，自然人股东填报“Z”。<br>2、参照《业务代码表》中的“行业类型代码”，填报代码。<br>3、对于经营范围涉及多个行业的情况，根据主要经营业务填报。 |
| 股权信息表 | 持股比例 | 股东在数据日期当日的持股比例，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。 | 1、填报股东在数据日期当日的持股比例。<br>2、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。 |
| 股权信息表 | 出资日期 | 该股东最近一次持股份额变化的日期。 | 1、填报股东最近一次持股份额变化的日期。<br>2、对于出资后持股比例未变化的情况，可参照工商登记信息变更日期或财务变更日期填报。 |
| 股权信息表 | 交易币种 | 参照《业务代码表》中的“币种代码”，填报代码。 | 参照《业务代码表》中的“币种代码”，填报代码。 |
| 股权信息表 | 交易币认缴金额 | 交易币认缴金额。针对非上市公司，“认缴金额”参照工商登记信息信息或公司章程；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 | 1、填报交易币认缴金额。<br>2、针对非上市公司，“认缴金额”参照工商登记信息信息或公司章程填报；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 |
| 股权信息表 | 本位币认缴金额 | 交易币按照既定规则的汇率折成的本位币认缴金额。单位：元。针对非上市公司，“认缴金额”参照工商登记信息信息或公司章程；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 | 1、填报交易币按照既定规则的汇率折成的本位币认缴金额。<br>2、单位：元。公司本位币非人民币时，应按财务收支币种进行填写。<br>3、针对非上市公司，“认缴金额”参照工商登记信息信息或公司章程填报；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 |
| 股权信息表 | 交易币出资金额 | 交易币出资金额。针对非上市公司，“出资金额”参照期末财务账面实收资本余额；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 | 1、填报交易币出资金额。<br>2、针对非上市公司，“出资金额”参照期末财务账面实收资本余额填报；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 |
| 股权信息表 | 本位币出资金额 | 交易币按照既定规则的汇率折成的本位币出资金额。单位：元。针对非上市公司，“出资金额”参照期末财务账面实收资本余额；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 | 1、填报交易币按照既定规则的汇率折成的本位币出资金额。<br>2、单位：元。公司本位币非人民币时，应按财务收支币种进行填写。<br>3、针对非上市公司，“出资金额”参照期末财务账面实收资本余额填报；针对上市公司，因均已完成全额实缴，认缴金额与出资金额一致，“认缴金额”、“出资金额”可参照期末财务账面股本余额填报，真实体现公司注册情况。 |
| 股权信息表 | 股东是否有效 | 参照《业务代码表》中的“是否判断代码”，填报代码。失效的主体，在失效当月再报一次。 | 1、参照《业务代码表》中的“是否判断代码”，填报代码。<br>2、失效的股东在失效当月应填报“02”。 |
| 股权信息表 | 是否有一致行动人 | 参照《业务代码表》中的“是否判断代码”，填报代码。一致行动人是指投资者通过协议、其他安排，与其他投资者共同扩大其所能够支配的一个公司股份表决权数量的行为或者事实。达成一致行动的相关投资者，为一致行动人。 | 1、参照《业务代码表》中的“是否判断代码”，填报代码。<br>2、一致行动是指投资者通过协议、其他安排，与其他投资者共同扩大其所能够支配的一个公司股份表决权数量的行为或者事实。达成一致行动的相关投资者，为一致行动人。<br>3、若仅有一位股东，不构成一致行动人。 |
| 股权信息表 | 一致行动人组别 | 是否有一致行动人为“是”时为必填。组别用数字填写。例如公司有6个股东，分别是A、B、C、D、E、F，其中A、B、C三方为一致行动人，D、E两方为另一组一致行动人，则A、B、C的一致行动人组别填写1，D、E的一致行动人组别填写2。 | 1、组别用数字填写。例如公司有6个股东，分别是A、B、C、D、E、F，其中A、B、C三方为一致行动人，D、E两方为另一组一致行动人，则A、B、C的一致行动人组别填写1，D、E的一致行动人组别填写2。<br>2、“是否有一致行动人”填报“01”时为必填。<br>3、“是否有一致行动人”填报“02”时，一致行动人组别应填报“9999999999”。 |
| 股权信息表 | 股权质押数量 | 截至报送日期，股东质押的股份数量。单位：股。若无抵押，则填0。 | 1、填报截至报送日期，股东质押的股份数量。<br>2、单位：股。<br>3、若无抵押，则填报“0”。 |
| 股权信息表 | 股权质押比例 | 截至报送日期，股东质押的股份数量占持股数量的比例，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。若无抵押，则填0。 | 1、填报截至报送日期，股东质押的股份数量占持股数量的比例。<br>2、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。<br>3、若无抵押，则填报“0”。 |
| 股权信息表 | 股权冻结数量 | 截至报送日期，股权冻结的股份数量。单位：股。若无冻结，则填0。 | 1、填报截至报送日期，股权冻结的股份数量。<br>2、单位：股。<br>3、若无冻结，则填报“0”。 |
| 股权信息表 | 股权冻结比例 | 截至报送日期，股东股权冻结的股份数量占持股数量的比例，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。若无抵押，则填0。 | 1、填报截至报送日期，股东股权冻结的股份数量占持股数量的比例。<br>2、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。<br>3、若无抵押，则填报“0”。 |
