# 立案信息表


---

人身保险公司（2024版）立案信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 立案信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 立案信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 立案信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 立案信息表 | 内部机构号 | 1、该立案受理机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 立案信息表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 立案信息表 | 报案号 | 1、保险公司在接到报案时按一定规则生成的编号，应具有唯一性。如不适用可为空。关联数据项：报案信息表-报案号。 | 1、报案号、立案号与赔案号可据实报送同一编号。 |
| 立案信息表 | 立案号 | 1、保险公司在立案时按一定规则生成的编号，应具有唯一性。其中，立案是指保险人受理索赔或给付请求并正式开始核赔的行为。 | 1、报案号、立案号与赔案号可据实报送同一编号。 |
| 立案信息表 | 立案日期 | 1、保险公司人工立案或理赔系统强制立案的时间。 | 1、对于立案结果为“不予立案”的情况，建议报送默认值“99990101”。 |
| 立案信息表 | 出险日期 | 1、理赔事故发生的时间，存在多次出险的，填写初次出险时间。 | 1、对于出险日期的确认可能在报案、立案或赔案环节存在不一致的情况，可以据实分别按照报案、立案或赔案环节记录的信息报送。<br>2、对于在案件结案前未完成采集出险日期的情况，报送默认值“99990101”，待出险日期确定后更新报送数据。 |
| 立案信息表 | 预估理赔金额 | 1、已立案案件的最近一次预估赔付金额。若在正式结案前，该案件的预估赔付金额发生变化，应重新报送一条数据；若在立案阶段无法明确预估赔付金额，填报“-1”。 |  |
| 立案信息表 | 预估日期 | 1、保险公司最近一次产生预估理赔金额的时间，应与预估理赔金额同步调整。 | 1、对于在立案阶段无法明确预估赔付金额时，建议按照不适用处理，报送99990101。 |
| 立案信息表 | 立案结果 | 1、案件受理结果或状态。<br>2、枚举值：已立案/准予立案；不予立案；案件撤销；其他。 | 1、若案件中途被删除并重新立案，建议报送其他，并填写“备注”进行情况说明。<br>2、对于报案人主动申请撤销报送案件撤销；对于保险公司主动关闭案件报送“其他”，并在“备注”中说明。<br>3、不予立案指案件未通过审核等环节，保险公司拒绝立案的情况。 |
| 立案信息表 | 备注 | 1、当“立案结果”为“不予立案”、“案件撤销”或“其他”时，必填，简要说明相关情况。 |  |
| 立案信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
