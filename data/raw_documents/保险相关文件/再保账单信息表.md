# 再保账单信息表


---

人身保险公司（2024版）再保账单信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 再保账单信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 再保账单信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 再保账单信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 再保账单信息表 | 账单分类 | 1、该账单对应的是分入业务还是分出业务。<br>2、枚举值：分出账单；分入账单。 |  |
| 再保账单信息表 | 账单编号 | 1、直保公司基于管理需要，赋予该账单的唯一标识号。 |  |
| 再保账单信息表 | 预提账单标志 | 1、该账单是否为预提账单。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、由于部分公司按照季度与再保公司结算，但会以月度为单位生成预提账单用于记账，因此设计“预提账单标志”数据项。<br>2、对于已结算账单（实际账单），“预提账单标志”填报0。 |
| 再保账单信息表 | 账单起期 | 1、分保账单的账单计算起始日期。 |  |
| 再保账单信息表 | 账单止期 | 1、分保账单的账单计算截止日期。 |  |
| 再保账单信息表 | 再保险公司代码 | 1、当“合同分类”为“分出”时，填报再保险业务分入公司的代码。优先填报保险业监督管理机构分配的机构代码。若无，填报由人身保险公司参照本规范定义的编码规则编制的唯一标识号。编码规则为：“再保险合作机构”七个字的拼音首字母缩写+三位顺序号，如ZBXHZJG001、ZBXHZJG002等。应在机构范围内具有唯一性。当“合同分类”为“分入”时，填报本机构保险机构代码。 |  |
| 再保账单信息表 | 再保险公司名称 | 1、与再保险公司代码相匹配的，再保险分入公司的名称，应填报机构工商登记或注册证件上的规范全称。 |  |
| 再保账单信息表 | 原保险公司代码 | 1、当“合同分类”为“分出”时，填报本机构保险机构代码。当“合同分类”为“分入”时，填报再保险业务分出公司的代码。优先填报保险业监督管理机构分配的机构代码。若无，填报由人身保险公司参照本规范定义的编码规则编制的唯一标识号。编码规则为：“再保险合作机构”七个字的拼音首字母缩写+三位顺序号，如ZBXHZJG001、ZBXHZJG002等。应在机构范围内具有唯一性。 |  |
| 再保账单信息表 | 原保险公司名称 | 1、填报与原保险公司代码相匹配的，再保险分出公司的名称，应填报机构工商登记或注册证件上的规范全称。 |  |
| 再保账单信息表 | 虚拟合同标志 | 1、识别以邮件方式达成的临时分保约定及其他未订立再保险合同的业务场景。当该标志为“1”时，表明与本账单相关的业务未订立单独的再保险合同。<br>通过该标志及虚拟合同号码，可实现上述场景下，再保账单与其保单明细的数据关联。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、对于根据再保合同约定，部分保单超出自动接受限额，向再保公司报送临分后，再保公司以原条件或新条件承接的情况，该类临分可以归属到所属分保产品对应的再保合同。<br>2、对于再保公司因不能承接部分业务，以临分方式分保到其他再保公司且未签订再保合同的情况下，虚拟合同标志填报“1”。<br>3、对于再保安排已经邮件确认、但是尚未完成合约签署、并且将会完成签署的合约，若后续不会产生再保账单，则暂不需要报送该表；若会产生再保账单，建议在合同尚未签署前，“虚拟合同标志”先“1”报送，并暂时报送相关虚拟合同号码，但在相关合同正式签署后，应将已报送数据的“虚拟合同标志”由“1”更新为“0”，并将虚拟合同号码更新为真实的合同号码。 |
| 再保账单信息表 | 再保险合同号码 | 1、当“虚拟合同标志”为“0”时，填报再保险合同或者附约号码。当该合同为主合同时，填写主合同号码；当该合同为附约合同时，填写附约合同号码。关联数据项：再保合同信息表-再保险合同号码。当“虚拟合同标志”为“1”时，填报与本账单相关的虚拟合同号码，该虚拟合同号码应在全公司系统内具有唯一性。 |  |
| 再保账单信息表 | 再保险合同名称 | 1、当“虚拟合同标志”为“0”时，填报再保险合同或附约的名称。当该合同为主合同时，填写主合同名称；当该合同为附约合同时，填写附约合同名称。关联数据项：再保合同信息表-再保险合同名称。当“虚拟合同标志”为“1”时，填报与本账单相关的虚拟合同名称。 |  |
| 再保账单信息表 | 分保费 | 1、分保费是指分出公司根据分保业务计算的应向分入公司分出的保费。 | 1、若账单金额本就含税，本表按照含税口径报送。 |
| 再保账单信息表 | 分保佣金 | 1、是分出公司向分入公司收取的报酬，主要用以分担和补偿分出公司为招揽业务和经营管理所需的费用开支。 | 1、建议包含盈余/纯益手续费金额。 |
| 再保账单信息表 | 退回分保费 | 1、指退保除外的部分保全业务产生的保费退还给分出公司。 | 1、若账单金额本就含税，本表按照含税口径报送。 |
| 再保账单信息表 | 退回分保佣金 | 1、账单期间发生保全业务变更导致的退回分保佣金。 |  |
| 再保账单信息表 | 摊回退保金 | 1、指退保引起的退保金从分入公司摊回。 |  |
| 再保账单信息表 | 摊回理赔款 | 1、指分出公司分保业务发生赔款后收到分入公司支付的应由其承担的赔款支出。 |  |
| 再保账单信息表 | 摊回满期金 | 1、指分出公司分保业务发生满期给付后，收到的由分入公司承担的满期金的摊回金额。 |  |
| 再保账单信息表 | 摊回生存金 | 1、指分出公司分保业务发生生存金给付后，收到的由分入公司承担的生存金的摊回金额。 |  |
| 再保账单信息表 | 结算状态 | 1、当“预提账单标志”为“0”时，必填。填报截至采集日期，该账单的结算状态。<br>2、枚举值：未结算；已结算。 |  |
| 再保账单信息表 | 结算日期 | 1、当“结算状态”为“已结算”时，必填。填报账单结付时收款或付款的日期。 |  |
| 再保账单信息表 | 货币代码 | 1、当“结算状态”为“已结算”时，必填。填报账单结算所使用的货币代码。<br>2、参照《业务代码表》“币种代码”，编号CD000009。 |  |
| 再保账单信息表 | 结算汇率 | 1、当“结算状态”为“已结算”时，必填。填报结算当日人民币和外币的比价，按公司记录情况报送。 |  |
| 再保账单信息表 | 账单交易流水编号 | 1、当“结算状态”为“已结算”时，必填。填报该账单对应的交易流水在人身保险公司内部的唯一标识号。关联数据项：交易流水表-交易流水编号。若结算当月尚未生成，报送“未生成”。 |  |
| 再保账单信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
