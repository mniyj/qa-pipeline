# C0105-信托计划融资人信息表


---

## C0105-信托计划融资人信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 信托计划融资人信息表 | 信托产品全称 | 信托计划全称。 | 1、填报信托计划全称。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 信托计划融资人信息表 | 产品登记编号 | 信托产品登记编码是指在中国信登所登记的信托产品唯一编码。 | 1、填报信托产品登记编码。信托产品登记编码是指在中国信登所登记的信托产品唯一编码。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 信托计划融资人信息表 | 信托产品代码 | 信托公司内部产品代码或编号。信托公司自定义，信托产品的内部唯一编号。 | 1、填报信托公司内部产品代码或编号。信托公司自定义，信托产品的内部唯一编号。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 信托计划融资人信息表 | 受托人法定名称 | 受托人法定名称。 | 1、填报受托人法定名称。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 信托计划融资人信息表 | 受托人证件类型 | 受托人证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报受托人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。 |
| 信托计划融资人信息表 | 受托人证件号码 | 受托人证件号码。 | 1、填报受托人证件号码。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 信托计划融资人信息表 | 受托人证件到期日 | 受托人证件到期日。 | 1、填报受托人证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 信托计划融资人信息表 | 融资人法定名称 | 填写融资人全称。若为自然人姓名，隐私，保险集团（控股）公司变形。 | 1、填报融资人全称。<br>2、若为自然人姓名，按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 信托计划融资人信息表 | 融资人证件类型 | 融资人证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报融资人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。 |
| 信托计划融资人信息表 | 融资人证件号码 | 融资人证件号码。若为自然人证件号码，隐私，保险集团（控股）公司变形 | 1、填报融资人证件号码。<br>2、不可填报集团EAST规范默认值或其他无效数据。<br>3、若为自然人证件号码，按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 信托计划融资人信息表 | 融资人证件到期日 | 融资人证件到期日。 | 1、填报融资人证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 信托计划融资人信息表 | 融资人类型 | 枚举值为“自然人；个体工商户；广义政府；非金融企业；金融机构（实体）；特定目的载体；境外”。 | 1、填报信托计划融资人类型。<br>2、按照枚举值“自然人；个体工商户；广义政府；非金融企业；金融机构（实体）；特定目的载体；境外”填报中文名称。 |
| 信托计划融资人信息表 | 融资人所属地区 | 参照《业务代码表》中的“行政区划代码”，填报代码。 | 参照《业务代码表》中的“行政区划代码”，填报代码。 |
| 信托计划融资人信息表 | 融资人所属行业 | 参照《业务代码表》中的“行业类型代码”，填报代码。 | 参照《业务代码表》中的“行业类型代码”，填报代码。 |
