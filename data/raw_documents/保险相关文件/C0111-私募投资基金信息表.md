# C0111-私募投资基金信息表


---

## C0111-私募投资基金信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 私募投资基金信息表 | 投资账户名称 | 机构投资账户名称，应具有唯一标识。 | 1、填报机构投资账户名称，应具有唯一标识。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 私募投资基金信息表 | 投资账户代码 | 机构投资账户代码，应具有唯一标识。 | 1、填报机构投资账户代码，应具有唯一标识。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 私募投资基金信息表 | 资产名称 | 填写确权登记等有关机构登记的资产名称，或有关机构备案名称。 | 填报确权登记等有关机构登记的资产名称，或有关机构备案名称。 |
| 私募投资基金信息表 | 资产代码 | 填写确权登记等有关机构登记的资产代码，或有关机构备案编码，若无填写机构自定义代码。 | 1、填报确权登记等有关机构登记的资产代码，或有关机构备案编码，若无填写机构自定义代码。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 私募投资基金信息表 | 投资期期限 | 填写基金投资期期限。 | 填报基金投资期期限。 |
| 私募投资基金信息表 | 退出期期限 | 填写基金退出期期限，期限单位需与投资期期限相同。 | 1、填报基金退出期期限。<br>2、期限单位需与投资期期限相同。 |
| 私募投资基金信息表 | 期限单位 | 填写基金期限单位。枚举值为“日；月；年”。 | 1、填报基金期限单位。<br>2、按照枚举值“日；月；年”填报中文名称。 |
| 私募投资基金信息表 | 管理方式 | 填写基金管理方式。枚举值为“参与；实际控制”。参与是指仅作为基金的出资人，不实际控制基金管理人；实际控制是指为基金管理人的第一大股东或出资人，并通过投资关系、协议或者其他安排，能够实际支配基金管理人行为。 | 1、填报基金管理方式。<br>2、按照枚举值“参与；实际控制”填报中文名称。参与是指仅作为基金的出资人，不实际控制基金管理人；实际控制是指为基金管理人的第一大股东或出资人，并通过投资关系、协议或者其他安排，能够实际支配基金管理人行为。 |
| 私募投资基金信息表 | 基金组织形式 | 填写基金组织形式。枚举值为“公司型；契约型；合伙型；其他”。 | 1、填报基金组织形式。<br>2、按照枚举值“公司型；契约型；合伙型；其他”填报中文名称。 |
| 私募投资基金信息表 | 境内外标识 | 基金境内外标识。参照《业务代码表》中的“境内外标识代码”，填报代码。 | 1、填报基金境内外标识。<br>2、参照《业务代码表》中的“境内外标识代码”，填报代码。 |
| 私募投资基金信息表 | 成立日期 | 填写基金成立日期。以基金在有关部门登记注册的日期为准。如无法获取，以合同签署日期为准。 | 1、填报基金成立日期。以基金在有关部门登记注册的日期为准。<br>2、如无法获取，以合同签署日期为准。 |
| 私募投资基金信息表 | 到期日期 | 填写基金到期日期。以投资合同中到期日期为准。如未到期，填写默认值99991231。 | 1、按照YYYYMMDD格式填报基金到期日期。<br>2、以投资合同中到期日期为准。<br>3、如未到期，填报默认值“99991231”。 |
| 私募投资基金信息表 | 普通合伙人法定名称 | 普通合伙人全称。“基金组织形式”为“合伙型”时必填。 | 1、填报普通合伙人全称。<br>2、“基金组织形式”为“合伙型”时必填。 |
| 私募投资基金信息表 | 普通合伙人证件类型 | 普通合伙人证件类型。“基金组织形式”为“合伙型”时必填。参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报普通合伙人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。<br>3、“基金组织形式”为“合伙型”时必填。 |
| 私募投资基金信息表 | 普通合伙人证件号码 | 普通合伙人证件号码。“基金组织形式”为“合伙型”时必填。 | 1、填报普通合伙人证件号码。<br>2、“基金组织形式”为“合伙型”时必填。 |
| 私募投资基金信息表 | 普通合伙人证件到期日 | 普通合伙人证件到期日。 | 1、填报普通合伙人证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 私募投资基金信息表 | 普通合伙人LEI编码 | 普通合伙人识别编码。 | 1、填报普通合伙人识别编码。<br>2、LEI是按照国际标准化组织ISO 17442标准为全球法人分配的唯一识别编码，LEI编码是由20位数字和字母组成的唯一编码。我国LEI编码包括前缀码部分、预留位部分、机构特定部分和校验位四部分。 |
| 私募投资基金信息表 | 基金管理人法定名称 | 基金管理人法定名称。 | 填报基金管理人法定名称。 |
| 私募投资基金信息表 | 基金管理人证件类型 | 基金管理人证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报基金管理人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。 |
| 私募投资基金信息表 | 基金管理人证件号码 | 基金管理人证件号码。 | 1、填报基金管理人证件号码。<br>2、基金管理人为境内机构时填写统一社会信用代码，基金管理人为境外机构时填写企业注册码、税务号等有效代码。 |
| 私募投资基金信息表 | 基金管理人证件到期日 | 基金管理人证件到期日。 | 1、填报基金管理人证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 私募投资基金信息表 | 基金管理人LEI编码 | 基金管理人全球法人识别编码。 | 1、填报基金管理人全球法人识别编码。<br>2、LEI是按照国际标准化组织ISO 17442标准为全球法人分配的唯一识别编码，LEI编码是由20位数字和字母组成的唯一编码。我国LEI编码包括前缀码部分、预留位部分、机构特定部分和校验位四部分。 |
| 私募投资基金信息表 | 有限合伙人名称 | 有限合伙人名称全称。如有多个需列填，以英文分号“;”分隔。 | 1、填报有限合伙人名称全称。<br>2、如有多个需列填，以以英文分号“;”分隔。 |
| 私募投资基金信息表 | 基金总规模 | 填写基金总规模。以投资合同中基金总规模为准。若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、填报基金总规模。以投资合同中基金总规模为准。<br>2、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>3、单位：元。 |
| 私募投资基金信息表 | 基金分类 | 填写基金分类。枚举值为“私募证券投资基金；私募证券类FOF基金；私募股权投资基金；私募股权投资类FOF基金；创业投资基金；创业投资类FOF基金；其他类别私募基金；其他类别私募FOF基金”。 | 1、填报基金分类。<br>2、按照枚举值“私募证券投资基金；私募证券类FOF基金；私募股权投资基金；私募股权投资类FOF基金；创业投资基金；创业投资类FOF基金；其他类别私募基金；其他类别私募FOF基金”填报中文名称。 |
| 私募投资基金信息表 | 投资方向 | 填写基金投资方向。枚举值为“综合；先进制造；能源；建筑；交通；电子信息；金融；房地产；医疗健康；教育文化；其他”。 | 1、填报基金投资方向。<br>2、按照枚举值“综合；先进制造；能源；建筑；交通；电子信息；金融；房地产；医疗健康；教育文化；其他”填报中文名称。 |
| 私募投资基金信息表 | 政策标签 | 填写基金政策标签。参照《业务代码表》中的“政策标签代码”，填报代码。可多选，如存在多个标签，以“;”隔开。如为其他，需在备注里描述。 | 1、填报基金政策标签。<br>2、参照《业务代码表》中的“政策标签代码”，填报代码。<br>3、可多选，如存在多个标签，以英文分号“;”分隔。如为其他，需在备注里描述。 |
| 私募投资基金信息表 | 投资阶段 | 填写基金投资阶段。枚举值为“天使投资；初创期投资；成长期投资；IPO前投资；并购投资；多个阶段投资；全阶段投资”。 | 1、填报基金投资阶段。<br>2、按照枚举值“天使投资；初创期投资；成长期投资；IPO前投资；并购投资；多个阶段投资；全阶段投资”填报中文名称。 |
| 私募投资基金信息表 | 基金状态 | 填写基金状态。枚举值为“投资期；退出期；清算期；已清盘；其他”。 | 1、填报基金状态。<br>2、按照枚举值“投资期；退出期；清算期；已清盘；其他”填报中文名称。 |
| 私募投资基金信息表 | 是否延期 | 填写基金是否延期。参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、填报基金是否延期。<br>2、参照《业务代码表》中的“是否判断代码”，填报代码。 |
| 私募投资基金信息表 | 延期原因 | 填写基金延期原因。如有延期计划或已发生延期，需注明原因。 | 1、填报基金延期原因。<br>2、如有延期计划或已发生延期，需注明原因。 |
| 私募投资基金信息表 | 总资产 | 填写基金总资产。若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、填报基金总资产。<br>2、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>3、单位：元。 |
| 私募投资基金信息表 | 净资产 | 填写基金净资产。若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、填报基金净资产。<br>2、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>3、单位：元。 |
| 私募投资基金信息表 | 累计营业收入 | 填写基金累计营业收入。若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、填报基金累计营业收入。<br>2、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>3、单位：元。 |
| 私募投资基金信息表 | 累计净利润 | 填写基金累计净利润。若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、填报基金累计净利润。<br>2、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>3、单位：元。 |
| 私募投资基金信息表 | 初始投资日期 | 初始投资日期。 | 1、填报初始投资日期。<br>2、不能填报99991231，或其他不合常理的日期。 |
| 私募投资基金信息表 | 初始份额占比 | 投资时点基金认购份额比例，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。 | 1、填报投资时点基金认购份额比例。<br>2、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。 |
| 私募投资基金信息表 | 投资币种 | 参照《业务代码表》中的“币种代码”，填报代码。 | 参照《业务代码表》中的“币种代码”，填报代码。 |
| 私募投资基金信息表 | 认缴金额 | 若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。 |
| 私募投资基金信息表 | 实缴金额 | 若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。 |
| 私募投资基金信息表 | 投资账面余额 | 若金额涉及到外币，由机构自行转换成人民币进行填报。单位：元。 | 1、若金额涉及到外币，由机构自行转换成人民币进行填报。<br>2、单位：元。 |
| 私募投资基金信息表 | 累计最新份额占比 | 数据填报口径为截至报送日上月月末数据，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。 | 1、数据填报口径为截至报送日上月月末数据。<br>2、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。 |
| 私募投资基金信息表 | 合计份额占比 | 存在保险集团（控股）公司及其保险子公司、保险公司及其投资控股的保险机构投资同一基金的情形时，填写合计持股比例，填数字，不填百分比，最少保留两位小数，比如12.34%填写为12.34。 | 1、填报合计份额占比。<br>2、当集团公司及其保险子公司、保险公司及其投资控股的保险机构投资同一基金的情形时，需填报合计持股比例。<br>3、填数字，不填百分比，精度为两位小数，比如12.34%填写为12.34。 |
| 私募投资基金信息表 | 已实现投资收益 | 数据填报口径为截至报送日上月月末数据，单位：元。 | 1、数据填报口径为截至报送日上月月末数据。<br>2、单位：元。 |
| 私募投资基金信息表 | 本年收益率 | 本年以来的收益率，需年化。填数字，不填百分比，最少保留四位小数，比如12.34%填写为0.1234。默认值99999。 | 1、填报本年以来的收益率，需年化。<br>2、填数字，不填百分比，精度为六位小数。如3.1234%填写为0.031234。默认值“99999”。 |
| 私募投资基金信息表 | 累计收益率 | 投资以来的累计收益率，填数字，不填百分比，最少保留四位小数，比如12.34%填写为0.1234。默认值99999。 | 1、填报投资以来的累计收益率。<br>2、填数字，不填百分比，精度为六位小数。如3.1234%填写为0.031234。默认值“99999”。 |
| 私募投资基金信息表 | 是否退出 | 参照《业务代码表》中的“是否判断代码”，填报代码。 | 参照《业务代码表》中的“是否判断代码”，填报代码。 |
| 私募投资基金信息表 | 退出日期 | 填写退出日期。“是否退出”为“是”时必填。 | 1、填报退出日期。<br>2、“是否退出”为“是”时必填。 |
| 私募投资基金信息表 | 退出方式 | 填写退出方式。“是否退出”为“是”时必填。枚举值为“份额转让，基金清算，赎回，其他”。 | 1、填报退出方式。<br>2、按照枚举值“份额转让；基金清算；赎回；其他”填报中文名称。<br>3、“是否退出”为“是”时必填。 |
| 私募投资基金信息表 | 备注 | 填写其他需要报送的但是目前无法标准化的信息，如有保底、保收益、结构化安排、抽屉协议、明股实债、集团内担保、替其他出资人垫资、承诺回购原出资人份额等情况需注明。 | 填报其他需要报送的但是目前无法标准化的信息，如有保底、保收益、结构化安排、抽屉协议、明股实债、集团内担保、替其他出资人垫资、承诺回购原出资人份额等情况需注明。 |
