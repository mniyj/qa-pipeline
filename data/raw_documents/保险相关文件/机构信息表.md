# 机构信息表


---

人身保险公司（2024版）机构信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 机构信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 机构信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 机构信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 机构信息表 | 全球法人识别编码 | 1、非自然人股东填报，如无，可为空。全球法人识别编码（LEI）是按照国际标准化组织的《金融服务法人机构识别编码》（ISO17442：2012）标准为法人机构分配的由20位数字和字母组成的唯一编码，可以用于标识与国际金融交易相关联的法人机构。 | 供参考：https://www.leichina.org/cei/2935720/2935943/index.html。该网址由北京国家金融标准化研究院有限责任公司（央行下属单位）运营。 |
| 机构信息表 | 工商注册日期 | 1、以工商注册的成立日期为准。 |  |
| 机构信息表 | 批复日期 | 1、保险行业保险公司开业批复文件的日期。 |  |
| 机构信息表 | 批复文号 | 1、保险行业保险公司开业批复文件的文号。 |  |
| 机构信息表 | 经营范围 | 1、应与工商注册中的经营范围一致。 |  |
| 机构信息表 | 注册资本 | 1、在工商机关注册时的资本金额。当注册资本发生变化时，应重新报送一条数据。 |  |
| 机构信息表 | 注册地所在省 | 1、注册地所在省，以营业执照登记信息为准。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 机构信息表 | 注册地所在地市 | 1、注册地所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 机构信息表 | 注册地所在区县 | 1、注册地所在区县，以营业执照登记信息为准。报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 机构信息表 | 注册地址 | 1、注册地详细地址，以营业执照登记信息为准。 |  |
| 机构信息表 | 上市公司标志 | 1、保险机构是否为上市公司的判别标识。根据《公司法》有关规定，上市公司指股票在证券交易所上市交易的股份有限公司。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 机构信息表 | 上市场所 | 1、当“上市公司标志”为“1”时，必填。填报保险公司股票上市场所的规范中文全称。如涉及多地上市，以英文半角分号分隔填列所有上市场所。<br>2、参照《业务代码表》“交易市场类型代码”，CD000027。 |  |
| 机构信息表 | 法定代表人姓名 | 1、指依法代表法人行使民事权利，履行民事义务的主要负责人的姓名，应与工商注册的姓名一致。 |  |
| 机构信息表 | 法定代表人证件类型 | 1、用于法定代表人身份识别的证件类型。填报代码。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 机构信息表 | 法定代表人证件类型中文名称 | 1、用于法定代表人身份识别的证件类型。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 机构信息表 | 法定代表人证件号码 | 1、用于法定代表人身份识别的证件号码，应与证件类型匹配。隐私，人身保险公司变形。 |  |
| 机构信息表 | 存在实际控制人标志 | 1、保险公司是否存在实际控制人。实际控制人认定标准参照《公司法》等相关法律的最新规定执行。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 机构信息表 | 实际控制人机构标志 | 1、当“存在实际控制人标志”为“1”时，必填。填报实际控制人是否为法人或非法人组织的标志。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 机构信息表 | 实际控制人名称 | 1、当“存在实际控制人标志”为“1”时，必填。实际控制人为自然人时，填报自然人姓名；为法人或非法人组织时，填报机构或组织的规范全称。 |  |
| 机构信息表 | 实际控制人证件类型 | 1、当“存在实际控制人标志”为“1”时，必填。个人优先填报居民身份证，法人或其他组织优先填报统一社会信用代码。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 机构信息表 | 实际控制人证件类型中文名称 | 1、当“存在实际控制人标志”为“1”时，必填。个人优先填报居民身份证，法人或其他组织优先填报统一社会信用代码。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 机构信息表 | 实际控制人证件号码 | 1、当“存在实际控制人标志”为“1”时，必填。填报与证件类型匹配的有效证件号码。自然人证件号码为隐私，人身保险公司变形。 |  |
| 机构信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
