# 委托投资账户关联信息表


---

人身保险公司（2024版）委托投资账户关联信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 委托投资账户关联信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 委托投资账户关联信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 委托投资账户关联信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 委托投资账户关联信息表 | 投资账户代码 | 1、人身保险公司委托投资账户代码，应具有唯一性。关联数据项：投资账户信息表-投资账户代码。 |  |
| 委托投资账户关联信息表 | 投资账户名称 | 1、人身保险公司委托投资账户名称。 |  |
| 委托投资账户关联信息表 | 资金托管账户开立机构名称 | 1、该委托投资账户所关联资金托管账户的开户机构名称，应与机构工商注册信息所使用的名称完全一致。 |  |
| 委托投资账户关联信息表 | 资金托管账户号码 | 1、该委托投资账户所关联资金托管账户的号码。关联数据项：账户信息表-账户账号。 |  |
| 委托投资账户关联信息表 | 资金托管账户名称 | 1、该委托投资账户所关联资金托管账户的规范全称。 |  |
| 委托投资账户关联信息表 | 关联关系有效标志 | 1、截至采集日期，该投资账户是否仍与该资金托管账户关联。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 委托投资账户关联信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
