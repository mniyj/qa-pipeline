| 销售人员直接佣金信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 销售人员直接佣金信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 销售人员直接佣金信息表 | 内部机构号 | 1、该笔佣金归属保单的承保机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 销售人员直接佣金信息表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 销售人员直接佣金信息表 | 保单团个性质 | 1、按个人、集体等特征划分的保单分类。<br>2、枚举值：团体；个人；团个均可。 |  |
| 销售人员直接佣金信息表 | 团体保单号 | 1、团体保单合同号，非团单填写默认值“000000”。关联数据项：团体保单表-团体保单号。 |  |

| 销售人员直接佣金信息表 | 个人保单号 | 1、个人保单合同号，团单可填写默认值“000000”。关联数据项：个人保单表-个人保单号。 |  |
| 销售人员直接佣金信息表 | 个单保险险种号码 | 1、该保单下险种在保险公司系统中的唯一标识（注意不是险种编码）。团单可填写默认值“000000”。关联数据项：个人险种表-个单保险险种号码。 |  |
| 销售人员直接佣金信息表 | 险种编码 | 1、保险公司系统中对该险种的唯一标识。关联数据项：险种定义表-险种编码。 |  |
| 销售人员直接佣金信息表 | 佣金年月 | 1、人身保险公司计提该笔佣金的年月。 |  |
| 销售人员直接佣金信息表 | 销售人员代码 | 1、填报该保单销售人员的工号或编号，应具有唯一性。关联数据项：销售人员信息表-销售人员代码。 |  |
| 销售人员直接佣金信息表 | 销售人员姓名 | 1、销售人员的姓名。 |  |
| 销售人员直接佣金信息表 | 业务类型 | 1、该笔佣金对应的业务类型。<br>2、参照《业务代码表》“佣金或手续费业务类型代码”，编号CD000046。 |  |
| 销售人员直接佣金信息表 | 费用序号 | 1、每笔佣金费用的唯一序号。同一佣金年月下该保单如存在多笔费用，按照费用计提时间先后，从1开始逐次编号。 | 1、本数据项主要为兼容同一佣金年月下某张保单如存在多笔费用，应按费用计提时间先后，从1开始逐次编号，即1、2、3..，例如一笔保单3个险种，如当月存在承保、犹豫期退保，应报送3条正值、3条负值共6条数据。 |
| 销售人员直接佣金信息表 | 货币代码 | 1、本笔佣金的计价货币代码。<br>2、参照《业务代码表》“币种代码”，编号CD000009。 |  |
| 销售人员直接佣金信息表 | 佣金比例 | 1、该笔佣金占保费的比例。填报口径以直接佣金率为准，应填报正值。 | 1、对于部分产品在实际测算销售人员该笔保单佣金时，会考虑多种因素，如职级等，因此系统中会记录原佣金与折后佣金两个的情况，如果确认折后佣金属于直接佣金的认定范畴，可按照折后佣金比例报送。<br>2、对于由于品质、投诉等原因导致全部或部分佣金扣发，按照扣减佣金的方式报送。 |
| 销售人员直接佣金信息表 | 佣金金额 | 1、该笔佣金的计提金额。 | 1、对于部分产品在实际测算销售人员该笔保单佣金时，会考虑多种因素，如职级等，因此系统中会记录原佣金与折后佣金两个的情况，如果确认折后佣金属于直接佣金的认定范畴，可按照折后佣金金额报送。<br>2、对于由于品质、投诉等原因导致全部或部分佣金扣发，按照扣减佣金的方式报送。 |
| 销售人员直接佣金信息表 | 保单承保机构所在省 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员直接佣金信息表 | 保单承保机构所在地市 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员直接佣金信息表 | 保单承保机构所在区县 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员直接佣金信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
