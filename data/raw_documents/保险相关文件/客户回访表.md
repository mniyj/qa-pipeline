# 客户回访表


---

人身保险公司（2024版）客户回访表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 客户回访表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 客户回访表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 客户回访表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 客户回访表 | 内部机构号 | 1、开展本次客户回访的机构（最细粒度）所对应的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 客户回访表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 客户回访表 | 团体保单号 | 1、针对部分因故需回访的团体保单，如以团单形式承保的家庭单，报送团体保单合同号，其余情况可为空。关联数据项：团体保单表-团体保单号。 | 1、如果公司系统内家庭单同时存在团单号与个单号，可同时报送团体保单号与个人保单号。 |
| 客户回访表 | 个人保单号 | 1、个人保单合同号，关联数据项：个人保单表-个人保单号。如以团单形式承保的家庭单，投保人非同时为被保险人，填报“000000”。 | 1、如果公司系统内家庭单同时存在团单号与个单号，可同时报送团体保单号与个人保单号。 |
| 客户回访表 | 回访顺序号 | 1、该保单每次回访的唯一顺序编号。即同一保单存在多次回访时应报送多条数据，且顺序号应按回访时间先后，从1开始依次累加。 |  |
| 客户回访表 | 销售渠道 | 1、保险经营机构向客户提供保险产品和服务的途径。<br>2、参照《业务代码表》“销售渠道类型代码”，编号CD000003。 |  |
| 客户回访表 | 投保人客户编号 | 1、投保人在保险公司的唯一客户标识。关联数据项：个人客户信息表-客户编号。 |  |
| 客户回访表 | 回访类型 | 1、对客户进行回访的类型。<br>2、枚举值：电话回访；电子回访；面访；信函回访；其他。 |  |
| 客户回访表 | 回访电话 | 1、当“回访类型”为“电话回访”时，必填。填写此次回访拨打的客户电话。隐私，人身保险公司变形。 |  |
| 客户回访表 | 投保单申请日期 | 1、客户填写投保单的日期。通常是投保单上客户签字日期，如果是电子投保单，则为投保单填写完成后的提交日期。 |  |
| 客户回访表 | 签单日期 | 1、合同签订的日期，即承保日期。 |  |
| 客户回访表 | 保单生效日期 | 1、依法成立的保险合同，根据法律规定或合同约定在保险合同当事人之间产生法律约束力的日期。 |  |
| 客户回访表 | 保单回执客户签收日期 | 1、客户签收保险合同回执的日期。 | 1、对于无回执签收日期但进行了回访的数据，填报99990101。 |
| 客户回访表 | 回访日期 | 1、本次回访的日期。 | 1、对于电子回访的情况，填报客户提交问卷的日期。 |
| 客户回访表 | 犹豫期天数 | 1、该保单的犹豫期天数。部分政保合作业务保单（如城乡居民大病业务保单）若存在回访但又不适用此项，报送“0”。 |  |
| 客户回访表 | 犹豫期截止日期 | 1、根据保险合同有关约定计算的本保单的犹豫期截止日期。部分政保合作业务保单（如城乡居民大病业务保单）若存在回访但又不适用此项，报送“99990101”。 | 1、对于无回执签收日期但进行了回访的数据，若约定犹豫期自签收回执之日起算，填报99990101。 |
| 客户回访表 | 犹豫期内回访标志 | 1、本次回访是否在保单犹豫期内进行。部分政保合作业务保单（如城乡居民大病业务保单）若存在回访但又不适用犹豫期安排，报送“1”。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、对于无回执签收日期但进行了回访的数据，若约定犹豫期自签收回执之日起算，填报0。 |
| 客户回访表 | 回访成功标志 | 1、根据《人身保险业务基本服务规定》（中国保险监督管理委员会令2010年第4号）第十五条：保险公司应当在犹豫期内对合同期限超过一年的人身保险新单业务进行回访，并及时记录回访情况。回访至少应当包括以下内容：<br>（一）确认受访人是否为投保人本人；<br>（二）确认投保人是否购买了该保险产品以及投保人和被保险人是否按照要求亲笔签名；<br>（三）确认投保人是否已经阅读并理解产品说明书和投保提示的内容；<br>（四）确认投保人是否知悉保险责任、责任免除和保险期间；<br>（五）确认投保人是否知悉退保可能受到的损失；<br>（六）确认投保人是否知悉犹豫期的起算时间、期间以及享有的权利；<br>（七）采用期缴方式的，确认投保人是否了解缴费期间和缴费频率。<br>人身保险新型产品的回访，中国保监会另有规定的，从其规定。<br>由各人身保险公司结合上述要求与业务实际情况判断本次回访是否成功。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、完成相关内容回访，即可视为回访成功；对回访内容有疑问，则应视为问题件并填报“问题件标志”。 |
| 客户回访表 | 问题件标志 | 1、当“回访成功标志”为“1”时，必填，用于判别本次回访是否为回访成功的问题件。回访中如发现投保人未收到保险合同、投保资料非本人签名、投保人对回访内容有疑义或作出否定回答等情况时，应结合具体产品类型、有关监管要求与实际业务管理情况判断本次回访是否视作问题件处理。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 客户回访表 | 回访发现的问题 | 1、当“问题件标志”为“1”时，必填。填写本次回访发现的具体问题。 | 1、对于具体文字表述，建议结合系统记录情况，以能令监管部门大致了解问题情况为原则报送信息。 |
| 客户回访表 | 保单承保机构所在省 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 客户回访表 | 保单承保机构所在地市 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 客户回访表 | 保单承保机构所在区县 | 1、该保单承保机构所对应内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 客户回访表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
