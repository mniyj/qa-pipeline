# 其他投资标的信息表


---

人身保险公司（2024版）其他投资标的信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 其他投资标的信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 其他投资标的信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 其他投资标的信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 其他投资标的信息表 | 投资账户代码 | 1、机构投资账户代码，应具有唯一性。关联数据项：投资账户信息表-投资账户代码。 |  |
| 其他投资标的信息表 | 投资账户名称 | 1、机构投资账户名称。 |  |
| 其他投资标的信息表 | 资产代码 | 1、机构自定义的资产代码，应在机构范围内具有唯一性。关联数据项：自主投资持仓表-资产代码。 |  |
| 其他投资标的信息表 | 资产名称 | 1、优先填写确权登记等有关机构登记的资产名称。若无，填写合同上的资产名称。 |  |
| 其他投资标的信息表 | 产品代码 | 1、确权登记等有关机构配发或备案的代码。如有，必填；若无，填报“无”。 |  |
| 其他投资标的信息表 | 主体序号 | 1、人身保险公司为每一相关主体赋予的顺序编号，应在同一“资产代码”下具有唯一性。 |  |
| 其他投资标的信息表 | 主体类型 | 1、该相关主体的类型。<br>2、枚举值：融资人；管理人；托管人；增信主体。 |  |
| 其他投资标的信息表 | 主体名称 | 1、该相关主体的姓名或规范全称。当该相关主体为自然人时，其姓名为隐私，应由人身保险公司变形；当该相关主体为法人或非法人组织时，填报与其工商注册信息一致的规范全称。 |  |
| 其他投资标的信息表 | 主体证件类型 | 1、该相关主体的证件类型，填报代码。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 | 1、对于政府债，若无法获取相关政府的证件信息，报送“2999”。 |
| 其他投资标的信息表 | 主体证件类型中文名称 | 1、该相关主体的证件类型，填报中文名称。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 | 1、对于政府债，若无法获取相关政府的证件信息，报送“其他证件（对公）。 |
| 其他投资标的信息表 | 主体证件号码 | 1、与该相关主体证件类型相匹配的证件号码。自然人证件号码为隐私，人身保险公司变形。 | 1、对于政府债，若无法获取相关政府的证件信息，报送“未记录”。 |
| 其他投资标的信息表 | 主体所属地区 | 1、该相关主体所在行政区划。除以下情况及其他可能存在的特例外，应填报省市县三级完整行政区划的名称：<br>（1）相关地区位于直辖市，如北京市海淀区；<br>（2）相关地区位于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县；<br>（3）相关地区位于未下设区县的市，如广东省东莞市、海南省儋州市；<br>（4）相关地区位于港澳台地区，如香港特别行政区。<br>如为除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 | 1、对于地方政府债，若无法逐一获取相关政府所在区县，报送省+市。 |
| 其他投资标的信息表 | 主体所属行业 | 1、该相关主体的所属行业分类，如涉及多个行业，填报业务占比最大的行业。<br>2、参照《业务代码表》“行业类型代码”，编号CD000007。 |  |
| 其他投资标的信息表 | 增信措施 | 1、当“主体类型”为“增信主体”时，填报具体增信措施，如同一增新主体涉及多项增信措施，应分别报送一条数据；当“主体类型”非“增信主体”时，填报“无”。<br>2、参照《业务代码表》“增信方式代码”，编号CD000045。 |  |
| 其他投资标的信息表 | 增信金额 | 1、该增信主体为本投资标的提供的增信金额中，本机构可获得的最大增信金额。若相关资产违约前无法确定具体金额，则按相关增信安排约定的上限金额报送，或暂时报送“-1”。当“主体类型”为“增信主体”时，必填。 |  |
| 其他投资标的信息表 | 备注 | 1、其他需补充说明的情况。 |  |
| 其他投资标的信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
