# 员工信息表


---

人身保险公司（2024版）员工信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 员工信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 员工信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 员工信息表 | 所属内部机构号 | 1、员工所属内部机构所对应的内部机构号（最细粒度）。关联数据项：分支机构信息表-内部机构号。 |  |
| 员工信息表 | 所属机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 员工信息表 | 员工编号 | 1、内部自定义的员工编号，应在人身保险公司机构范围内具有唯一性。一般由英文字母、数字、常见字符组成。 |  |
| 员工信息表 | 员工姓名 | 1、员工身份证或护照的姓名。 |  |
| 员工信息表 | 个人证件类型 | 1、员工的证件类型。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 员工信息表 | 个人证件类型中文名称 | 1、员工的证件类型名称。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 员工信息表 | 个人证件号码 | 1、与证件类型相匹配的证件号码。隐私，人身保险公司变形。 |  |
| 员工信息表 | 性别 | 1、员工性别。<br>2、枚举值为：01；02；03；04。 |  |
| 员工信息表 | 出生年月 | 1、员工出生年月。 |  |
| 员工信息表 | 外籍员工标志 | 1、根据《中华人民共和国国籍法》有关规定，该员工是否不具有中国国籍。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、对于港、澳、台员工，建议该数据项报送0。 |
| 员工信息表 | 关键人员标志 | 1、该员工是否本机构关键人员。其中，关键人员的定义参照《中国银保监会关于银行保险机构员工履职回避工作的指导意见》等相关规定执行。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 员工信息表 | 民族 | 1、当“外籍员工标志”为“0”时，必填。填报员工所属民族。<br>2、参照《业务代码表》“民族代码”，编号CD000004。 |  |
| 员工信息表 | 政治面貌 | 1、当“外籍员工标志”为“0”时，必填。填报员工个人政治面貌。<br>2、参照《业务代码表》“政治面貌代码”，编号CD000026。 |  |
| 员工信息表 | 参加政党日期 | 1、参加政党的日期。 | 根据《中国共产主义青年团章程》，中国共产主义青年团是中国共产党领导的先进青年的群团组织（非政党组织），可暂不填报<参加政党日期>。 |
| 员工信息表 | 学历 | 1、员工最高学历。<br>2、参照《业务代码表》“学历代码”，编号CD000041。 | 1、对于境外留学仅有学位证书而无学历证书的情况，建议结合中国教育部留学服务中心的学历认证情况报送数据。若已获得上述机构的学历认证，可按照在国内外获得的最高学位报送该数据项。 |
| 员工信息表 | 职业资格 | 1、员工职业资格，如果存在多个职业资格以英文半角分号分隔报送。<br>2、参照《业务代码表》“职业资格代码”，编号CD000025。 |  |
| 员工信息表 | 联系电话 | 1、员工联系电话，区号-座机电话/手机。 | 1、结合各公司实际管理情况报送数据，若无座机号，应报送手机号；若报送座机号，不可统一报送前台号码。 |
| 员工信息表 | 董监高标志 | 1、表示该员工在该内部机构是否属于保险业监督管理机构监管的董事、监事、高管范围。董监高人员范围参照《保险公司董事、监事和高级管理人员任职资格管理规定》等有关法律法规的最新规定认定。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 员工信息表 | 员工编制 | 1、填报员工编制。正式员工指与保险机构签订劳动合同的员工。非员工董监高人员是指未与本保险机构签订劳动合同的董事、监事、高级管理人员。<br>2、枚举值：正式员工；非员工董监高人员；退休返聘员工。 |  |
| 员工信息表 | 员工状态 | 1、该员工在对应所属内部机构的任职状态。当该员工所任职的内部机构发生变化时，原任职机构已报送数据的“员工状态”应填报为“离职”，新任职机构的“员工状态”应填报为“在职”。<br>2、枚举值：在职；待岗；离职；停职；退休；长期休假；内退；其他。 |  |
| 员工信息表 | 所属部门 | 1、填报保险公司组织架构的实际部门，如存在多级部门，上下级部门间用“-”链接。例如：“一级部门名称-二级部门名称”。按公司内部规定名称填写。当“董监高标志”为“0”时，必填。 | 根据公司对于相关人员的实际管理情况报送其所属部门或管理部门，若确无，据实报送“不适用”，并在报送数据时进行报备说明。 |
| 员工信息表 | 入职日期 | 1、填报该员工入职该机构的日期，以人身保险公司系统记录时间为准。非公司员工的董事、监事填报任职开始日期。 | 1、对于复聘员工，建议结合复聘人员“员工编号”的变化情况考虑：（1）若“员工编号”变化，则应以新的“员工编号”报送一条新数据。（2）若“员工编号”不变，建议据实更新“入职日期”。其余与员工相关的信息表也应根据《员工信息表》的报送情况同步调整。<br>2、对于签署劳动合同的高管人员，该表中的“入职日期”按照加入相关机构的日期填报。上任高管岗位的日期在《员工岗位信息表》中的“上岗日期”中填报。 |
| 员工信息表 | 离职日期 | 1、该员工离开该内部机构的日期，非公司员工的董事、监事填报任职结束日期。以人身保险公司系统记录的时间为准。若未离开该内部机构或仍在任职期，填报默认值99990101。 | 1、对于签署劳动合同的高管人员，该表中的“离职日期”按照离开相关机构的日期填报。卸任管岗位的日期在《员工岗位信息表》中的“离岗日期”中填报。 |
| 员工信息表 | 银行名称 | 1、员工工资卡对应开户银行的名称。 | 尽可能按照最细粒度的开户行信息报送。 |
| 员工信息表 | 银行账号 | 1、员工工资卡账号。 |  |
| 员工信息表 | 银行账户名称 | 1、员工工资卡银行账户名称。 |  |
| 员工信息表 | 内部机构所在省 | 1、该员工所属内部机构注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工信息表 | 内部机构所在地市 | 1、该员工所属内部机构注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工信息表 | 内部机构所在区县 | 1、该员工所属内部机构注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 员工信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
