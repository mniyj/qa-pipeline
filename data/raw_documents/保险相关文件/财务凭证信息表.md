# 财务凭证信息表


---

人身保险公司（2024版）财务凭证信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 财务凭证信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 财务凭证信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 财务凭证信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 财务凭证信息表 | 内部机构号 | 1、该凭证所属内部机构所对应的内部机构号（最细粒度）。关联数据项：分支机构信息表-内部机构号。 |  |
| 财务凭证信息表 | 机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 财务凭证信息表 | 保险账套编码 | 1、保险公司内部账套编码，应具有唯一性。 |  |
| 财务凭证信息表 | 保险账套名称 | 1、保险公司内部账套名称，应具有唯一性。 |  |
| 财务凭证信息表 | 会计期间 | 1、凭证的归属期间。 | 根据实际记账情况报送。 |
| 财务凭证信息表 | 记账日期 | 1、凭证的记账日期。 |  |
| 财务凭证信息表 | 记账凭证号 | 1、保险公司内部根据一定的规则编制的凭证编号，为唯一标识。 |  |
| 财务凭证信息表 | 总账会计科目编号 | 1、保险公司内部使用的科目编码。关联数据项：内部科目对照表-总账会计科目编号。 |  |
| 财务凭证信息表 | 总账会计科目名称 | 1、保险公司内部使用的科目名称。关联数据项：内部科目对照表-总账会计科目名称。 |  |
| 财务凭证信息表 | 凭证来源 | 1、凭证的系统来源。例如：投资系统、核心系统、资金系统、手工、电子表格。 |  |
| 财务凭证信息表 | 摘要 | 1、记账凭证摘要。 |  |
| 财务凭证信息表 | 交易币币种代码 | 1、填报市场上流通的各种货币币种的统一标识。填报字母代码。例如：CNY、EUR、JPY等。<br>2、参照《业务代码表》“币种代码”，编号CD000009。 |  |
| 财务凭证信息表 | 交易币借方发生额 | 1、当前科目交易币借方发生金额。交易币币种代码为CNY时，可为空；为其他代码时，必填。 |  |
| 财务凭证信息表 | 交易币贷方发生额 | 1、当前科目交易币贷方发生金额。交易币币种代码为CNY时，可为空；为其他代码时，必填。 |  |
| 财务凭证信息表 | 本位币借方发生额 | 1、当前科目本期本位币借方发生额，单位人民币元。 |  |
| 财务凭证信息表 | 本位币贷方发生额 | 1、当前科目本期本位币贷方发生额，单位人民币元。 |  |
| 财务凭证信息表 | 业务系统险种编码 | 1、保险公司业务系统记录的险种编码，对应险种定义表中的险种编码。对于直接佣金/手续费等与险种直接相关的销售费用，原则上必填。如该凭证无法关联到险种，填写“不适用”。 | 1、对于一个财务系统产品编码对应多个业务系统产品编码，无法根据凭证拆分的情况，建议据实报送多个。 |
| 财务凭证信息表 | 财务系统险种编码 | 1、保险公司财务系统记录的险种编码。如该凭证无法关联到险种，填写“不适用”。 |  |
| 财务凭证信息表 | 缴费方式名称 | 1、保险公司财务系统中缴费方式名称。 |  |
| 财务凭证信息表 | 渠道名称 | 1、保险公司财务系统中渠道名称。 |  |
| 财务凭证信息表 | 统计分险种 | 1、需要对应到统计分险种的科目有：保费收入、手续费及直接佣金、保户储金及投资款、赔付支出、退保金、独立账户负债。<br>2、参照《业务代码表》“财务分险种代码”，编号CD000015。 |  |
| 财务凭证信息表 | 统计产品设计类型 | 1、按照人身险条款对投保人提供的服务内容进行划分，需要对应到统计产品设计类型的科目有：保费收入、手续费及直接佣金、应收保费、保户储金及投资款、赔付支出、退保金。填报中文描述。<br>2、枚举值：普通型产品；分红型产品；万能型产品；投资连结型产品；其他新型产品。 |  |
| 财务凭证信息表 | 统计缴费方式 | 1、统计保费的缴费方式。对月缴、季缴情况，第一次缴费属于首年首期，第一年的其他缴费属于首年续期，第二年及以后属于续期。需要对应到统计缴费方式的科目有：保费收入。填报中文描述。<br>2、枚举值：首年首期；首年续期；趸交；续期；其他。 |  |
| 财务凭证信息表 | 统计渠道 | 1、需要对应到统计渠道的科目有：保费收入、手续费及佣金。<br>2、参照《业务代码表》“财务销售渠道类型代码”，编号CD000016。 |  |
| 财务凭证信息表 | 内部机构所在省 | 1、该内部机构注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 财务凭证信息表 | 内部机构所在地市 | 1、该内部机构注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 财务凭证信息表 | 内部机构所在区县 | 1、该内部机构注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 财务凭证信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
