# 中介机构手续费信息表

人身保险公司（2024版）中介机构手续费信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 中介机构手续费信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 中介机构手续费信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 中介机构手续费信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 中介机构手续费信息表 | 所属内部机构号 | 1、与该中介机构实际开展业务合作的内部机构号（最细粒度）。关联数据项：分支机构信息表-内部机构号。 |  |
| 中介机构手续费信息表 | 所属机构名称 | 1、与内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 中介机构手续费信息表 | 中介机构代码 | 1、保险公司分配给各中介机构唯一标识号。关联数据项：中介机构信息表-中介机构代码。 |  |
| 中介机构手续费信息表 | 中介机构名称 | 1、应与中介机构工商注册信息所使用的名称完全一致。关联数据项：中介机构信息表-中介机构名称。 |  |
| 中介机构手续费信息表 | 中介机构统一编码 | 1、中介机构在中介监管系统中登记的机构编码：法人机构，取法人机构编码；非法人机构，取网点机构编码。 |  |
| 中介机构手续费信息表 | 手续费发放年月 | 1、实际支付手续费的年月。例如：2023年1月25日支付手续费，手续费年月为202301。 | 1、本表报送每月向各中介机构实际已支付的手续费金额，此处报送每笔手续费实际发放的年月。 |
| 中介机构手续费信息表 | 发放序号 | 1、报送期内给该中介机构发放手续费的序号，从1开始依次递增。 | 1、按照按照单个中介机构编号，对于公司存在不同部门与同一家中介机构签署协议并支付手续费的情况，如果相关部门均归属于同一内部机构（例如均归属于总公司或某省分公司），此处可在总公司或省分公司的“内部机构号”下排序，无需按照部门粒度排序。 |
| 中介机构手续费信息表 | 货币代码 | 1、支付手续费所使用的货币币种。<br>2、参照《业务代码表》“币种代码”，编号CD000009。 |  |
| 中介机构手续费信息表 | 手续费总额 | 1、每月实际支付的手续费总额（税前）。 | 1、对于健康险结算策略为各自结算的情况，主共不算从共的手续费，如果公司支付的手续费总额仅包含本公司部分，则手续费总额与实际负担手续费金额可据实报送一致数据。 |
| 中介机构手续费信息表 | 实际负担手续费金额 | 1、每月实际负担的手续费金额（税前）。填报要求如下：（1）当联共保场景下，参保公司约定由主承保机构统一向中介机构支付手续费时，此处填报本机构实际承担的手续费金额。示例：某联共保项目共涉及10家保险公司，且该项目合计应向某中介机构支付手续费10万元。其中，应由主承保机构承担的手续费共计2万元，应由其余9家参保机构承担的手续费共计8万元。则对于主承保机构，本表中的“手续费总额”报送100000，“实际负担手续费金额”报送20000。（2）若不涉及（1）中所述情形，此处的填报内容应与“手续费总额”保持一致。 | 1、对于健康险结算策略为各自结算的情况，主共不算从共的手续费，如果公司支付的手续费总额仅包含本公司部分，则手续费总额与实际负担手续费金额可据实报送一致数据。 |
| 中介机构手续费信息表 | 手续费交易流水编号 | 1、发放手续费总额所对应的交易流水在人身保险公司内部的唯一标识号。关联数据项：交易流水表-交易流水编号。 |  |
| 中介机构手续费信息表 | 账户开立机构名称 | 1、该中介机构收取该笔手续费所使用账户（银行账户、第三方支付账户等）或数字货币钱包对应的开户机构名称，应与相关机构的工商注册信息保持一致。 |  |
| 中介机构手续费信息表 | 账户账号 | 1、该中介机构收取该笔手续费所使用的账户账号（银行账号、第三方支付账号等）或数字货币钱包的编号。 |  |
| 中介机构手续费信息表 | 账户户名 | 1、该中介机构收取该笔手续费所使用的账户（银行账户、第三方支付账户等）或数字货币钱包的名称。 |  |
| 中介机构手续费信息表 | 内部机构所在省 | 1、与该中介机构实际开展业务合作的内部机构的注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 中介机构手续费信息表 | 内部机构所在地市 | 1、与该中介机构实际开展业务合作的内部机构的注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 中介机构手续费信息表 | 内部机构所在区县 | 1、与该中介机构实际开展业务合作的内部机构的注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 中介机构手续费信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
