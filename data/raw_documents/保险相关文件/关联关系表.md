# 关联关系表


---

人身保险公司（2024版）关联关系表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 关联关系表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 关联关系表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 关联关系表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 关联关系表 | 关联方名称/关联方中间节点名称 | 1、关联方名称填写法人或非法人组织的名称、自然人姓名。关联方中间节点名称填写金融产品名称。关联数据项：关联方信息表-关联方名称/金融产品信息表-金融产品全称。 |  |
| 关联关系表 | 关联方代码/关联方中间节点代码 | 1、关联方代码填写人身保险公司赋予该关联方的内部标识号，关联方中间节点代码填写金融产品编号。关联数据项：关联方信息表-关联方代码/金融产品信息表-金融产品编号。 |  |
| 关联关系表 | 关联方/关联方中间节点类型 | 1、关联方/关联方中间节点类型，填报中文名称。<br>2、枚举值：法人或非法人组织；自然人；金融产品等其他。 |  |
| 关联关系表 | 前一层关联方名称/关联方中间节点名称 | 1、填写前一层法人或非法人组织的名称、自然人姓名、金融产品的产品全称。关联数据项：关联方信息表-关联方名称/金融产品信息表-金融产品全称。 |  |
| 关联关系表 | 前一层关联方代码/关联方中间节点代码 | 1、填写前一层关联方的唯一标识号。关联方代码填写人身保险公司赋予该关联方的内部标识号，关联方中间节点代码填写金融产品编号。关联数据项：关联方信息表-关联方代码/金融产品信息表-金融产品编号。 |  |
| 关联关系表 | 前一层关联方/关联方中间节点类型 | 1、前一层关联方/关联方中间节点类型，填报中文名称。<br>2、枚举值：法人或非法人组织；自然人；金融产品等其他。 |  |
| 关联关系表 | 与前一层的关联关系 | 1、与前一层的关联关系，填报中文描述。当同时存在多种关联关系时，优先填报109、111、112、116、119对应的关联关系名称。<br>2、参照《业务代码表》“关联关系类型代码”，编号CD000024。 |  |
| 关联关系表 | 与前一层之间是否有权益份额 | 1、与前一层之间是否有权益份额，填报中文描述。<br>2、枚举值：是，对前一层持有；是，被前一层持有；否。 |  |
| 关联关系表 | 持有比例 | 1、当“与前一层之间是否有权益份额”填报“是，对前一层持有”和“是，被前一层持有”时，必填。填报持有或被前一层关联方持有权益份额的比例。按百分比报送。如持股比例为10.50%，则填报10.50，不需要带百分号。当该比例小于0.01%时，此处按照“0.01”填报，并在“关联关系说明”中说明实际持有的比例。 |  |
| 关联关系表 | 质押股权比例 | 1、当填报机构为前一层关联方时，关联方持有前一层关联方的质押股权数量占持有的股权总量的比例。当“与前一层之间是否有权益份额”填报“是，对前一层持有”和“是，被前一层持有”时，必填。按百分比报送。如质押股权数量占持股比例的50.30%，则填报50.30。 |  |
| 关联关系表 | 关联关系说明 | 1、形成关联关系的原因说明。 |  |
| 关联关系表 | 关系有效标志 | 1、该关联关系是否有效的标志。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 关联关系表 | 生效日期 | 1、按照监管规定认定为关联方的时间。 |  |
| 关联关系表 | 失效日期 | 1、当“关系有效标志”为“0”时，必填。填报按照监管规定不再认定为关联方的时间。 |  |
| 关联关系表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
