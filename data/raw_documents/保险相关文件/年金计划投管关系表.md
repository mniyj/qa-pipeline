# 年金计划投管关系表


---

人身保险公司（2024版）年金计划投管关系表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 年金计划投管关系表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 年金计划投管关系表 | 保险机构代码 | 1、人身保险公司总公司机构代码，此处填报受托人对应法人的保险机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 年金计划投管关系表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 年金计划投管关系表 | 年金计划编码 | 1、受托机构自行定义的，在机构内部唯一的编码。关联数据项：年金计划信息表-年金计划编码。 |  |
| 年金计划投管关系表 | 年金计划登记号 | 1、年金计划确认函中的年金计划登记号。关联数据项：年金计划信息表-年金计划登记号。 |  |
| 年金计划投管关系表 | 投管合同号 | 1、投资管理合同号码。 |  |
| 年金计划投管关系表 | 投管合同生效日期 | 1、填写投管合同的生效日期。 | 1、可参照公司实际管理情况填报m例如参照报送人社部相关信息口径，按照实际运作日期（已打款，单位净值为1的当天），来计算合同生效日期。 |
| 年金计划投管关系表 | 投管合同终止日期 | 1、填写投管合同的终止日期，若合同中未约定终止日期或存在自动顺延条款，可暂时报送99990101。 |  |
| 年金计划投管关系表 | 投管人机构名称 | 1、投资管理人的组织机构名称。按年金资质证明上注明的机构名称填报。 |  |
| 年金计划投管关系表 | 投管人证件类型 | 1、投管人的证件类型代码，优先填报统一社会信用代码（即2010）。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 年金计划投管关系表 | 投管人证件类型中文名称 | 1、投管人证件类型中文名称。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 年金计划投管关系表 | 投管人证件号码 | 1、填报与证件类型相匹配的证件号码。 |  |
| 年金计划投管关系表 | 投管人法定代表人姓名 | 1、投资管理人的法定代表人，应与工商注册的姓名一致。 |  |
| 年金计划投管关系表 | 投资管理标准费率 | 1、投资管理合同中投管费收取标准。如有公式请列出并加以说明。 |  |
| 年金计划投管关系表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
