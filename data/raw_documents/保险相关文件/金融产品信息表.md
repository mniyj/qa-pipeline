# 金融产品信息表


---

人身保险公司（2024版）金融产品信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 金融产品信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 金融产品信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 金融产品信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 金融产品信息表 | 金融产品编号 | 1、人身保险公司赋予该金融产品的内部编号，应在机构范围内具有唯一性。 |  |
| 金融产品信息表 | 金融产品全称 | 1、金融产品在批准、注册或备案后的产品名称。 |  |
| 金融产品信息表 | 产品批准/注册/备案号 | 1、产品批准、注册或备案机构配发的核准编号。如产品报送时产品批准、注册或备案号尚未公布，可暂时为空；待后续产品批准、注册或备案号公布后应及时更新。 |  |
| 金融产品信息表 | 产品代码 | 1、由产品登记机构配发的产品代码。 |  |
| 金融产品信息表 | 产品分类 | 1、金融产品分类，填报中文描述。<br>2、参照《业务代码表》“金融产品分类代码”，编号CD000062。 |  |
| 金融产品信息表 | 产品登记机构 | 1、为金融产品及份额等信息提供登记、托管等服务的机构名称，应与机构工商注册名称保持一致。当产品登记机构与产品托管机构不一致时，优先填报登记机构的名称。 |  |
| 金融产品信息表 | 产品管理人全称 | 1、发起金融产品设立、募集，并提供后续管理的金融机构名称。 |  |
| 金融产品信息表 | 管理人统一社会信用代码 | 1、金融产品管理人的统一社会信用代码。 |  |
| 金融产品信息表 | 产品托管人全称 | 1、负责本金融产品托管业务的金融机构名称。 |  |
| 金融产品信息表 | 托管人统一社会信用代码 | 1、金融产品托管人的统一社会信用代码。 |  |
| 金融产品信息表 | 底层资产 | 1、填报金融产品的底层资产情况。 |  |
| 金融产品信息表 | 投资者 | 1、结合有关监管要求及各公司关联交易实际管理情况，以可取得的信息填报该金融产品的其他投资者情况。 |  |
| 金融产品信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
