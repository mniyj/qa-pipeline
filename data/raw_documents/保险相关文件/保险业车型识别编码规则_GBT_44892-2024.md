保险业车型识别编码规则


1、范围


本文件规定了保险行业中车型代码及车型识别代码的编码规则。


本文件适用于保险行业业务中的投保车型标识、风险识别活动和管理。


2、规范性引用文件


下列文件中的内容通过文中的规范性引用而构成本文件必不可少的条款。其中，注日期的引用文件，仅该日期对应的版本适用于本文件；不注日期的引用文件，其最新版本（包括所有的修改单）适用于本文件。


GA802—2019道路交通管理机动车类型


3、术语和定义


下列术语和定义适用于本文件。


3.1 车型 vehicle type


车型是指根据车辆品牌、车系、配置款型确定的具体车辆类型。


3.2 车型识别代码 code of vehicle type identification


车型识别代码是指保险业中标识车型风险因素的代码。注：车型风险发生变化，车型识别代码也随之发生变化，该代码属于动态代码。


4、编码规则


4.1 代码结构


车型识别代码采用17位数字和字母混合码，由车型代码、类别代码、系别代码和风险代码复合而成。车型识别代码结构示意图如图1所示。

4.2 车型代码


4.2.1 车型代码结构


车型代码采用12位数字和字母混合码，由版本代码、品牌代码、车系代码、配置款型代码、顺序码复合而成。车型代码结构示意图如图2所示。


图2 车型代码结构示意图


4.2.2 版本代码


版本代码采用1位英文字母表示。


4.2.3 品牌代码


品牌是指汽车制造商命名的汽车商品的名称或同一厂家使用的注册商标的中文名称，使用车辆公告名称或海关签注的中文名称。


品牌代码采用3位大写英文字母表示，其中前2位为品牌前两位汉字的首字母，第3位英文字母为计算机随机赋值，从A到Z。不同品牌代码不应重复。


4.2.4 车系代码


车系是指同一品牌下不同的车辆商品名称或车辆系列名称，通常一个品牌下有多个车系。


车系代码采用2位大写英文字母表示。同一品牌车系代码不应重复。


4.2.5配置款型代码


配置款型是指厂商正式公布的销售车型的配置等级说明。配置款型代码采用2位大写英文字母表示，与各车型“配置等级”进行对应，配置款型代码见表1。对于没有配置等级的车型：


—商用车配置按基本款定型，若有多款车型，配置款型按价格高低依次排列为基本、标准、舒适和豪华4种类型；


—乘用车根据平均价格相近有配置的车型进行确定配置，配置款型使用基本、标准、舒适和豪华4种类型。


表1 配置款型代码表


| 配置款型代码 | 配置款型名称 |
| --- | --- |
| UA | 基本 |
| UB | 标准 |
| UC | 舒适 |
| UD | 豪华 |
| UE | 运动 |
| UF | 纪念 |
| UG | 限量 |


4.2.6 顺序码


顺序码用于区分同一车系同一配置款型下的不同车型。顺序码采用4位数字表示，按照顺序从“0001”到“9999”。


4.3 类别代码


类别是指汽车所属的分类，主要包括载客汽车、载货汽车、专项作业车、摩托车、全挂车、中置轴挂车、半挂车、轮式专用机械车等。


类别代码采用1位数字表示，按照GA802—2019中的机动车结构分类要求，具体见表2。

4.4 系别代码


系别是指车辆生产地的属性，如国产、合资、进口等。


系别代码采用1位数字表示，具体见表3。

4.5 风险代码


风险代码是指车型所对应的具体风险等级。具体风险等级由保险业根据车型损失费率分级厘定。


风险代码采用1位大写英文字母和2位数字的组合码表示，按照顺序从“A01”到“Z99”。
