# A0304-成员公司董监高履职信息表


---

## A0304-成员公司董监高履职信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 成员公司董监高履职信息表 | 成员公司员工代码 | 指《成员公司员工信息表》中公司内部自行定义的员工代码，具有唯一性。若外部董监事无员工代码，可填写默认值。 | 1、填报成员公司内部自行定义的成员公司员工代码，具有唯一性。一般由英文字母、数字、常见字符组成。<br>2、员工代码不可填报证件号码或集团EAST规范默认值或其他无效数据。<br>3、报送的所有期次A0303<成员公司机构处罚信息表>、A0304<成员公司董监高履职信息表>、A0305<成员公司董监高处罚信息表>、A0306<成员公司管理人员信息表>中，员工与员工代码保持一一对应的关系。 |
| 成员公司董监高履职信息表 | 成员公司员工法定名称 | 员工有效身份证件上的姓名。隐私，保险集团（控股）公司变形。 | 1、填报员工有效身份证件上的姓名。<br>2、员工信息应与本公司填报的A0306<成员公司管理人员信息表>中信息保持一致。<br>3、在填报涉及集团公司员工信息时，以A0204<员工信息表>或A0206<董监高履职信息表>中相应信息为准。在填报涉及其他成员公司员工信息时，应互相保持一致。<br>4、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 成员公司董监高履职信息表 | 成员公司员工证件类型 | 参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、参照《业务代码表》中的“证件类型代码”填报代码。<br>2、需与“成员公司员工证件号码”对应类型一致。<br>3、员工信息应与本公司填报的A0306<成员公司管理人员信息表>中信息保持一致。<br>4、在填报涉及集团公司员工信息时，以A0204<员工信息表>或A0206<董监高履职信息表>中相应信息为准。在填报涉及其他成员公司员工信息时，应互相保持一致。 |
| 成员公司董监高履职信息表 | 成员公司员工证件号码 | 身份证号、护照号等有效证件号码，隐私，保险集团（控股）公司变形。 | 1、填报身份证号、护照号等有效证件号码。<br>2、董监高为中华人民共和国公民时，优先填居民身份证。<br>3、员工信息应与本公司填报的A0306<成员公司管理人员信息表>中信息保持一致。<br>4、在填报涉及集团公司员工信息时，以A0204<员工信息表>或A0206<董监高履职信息表>中相应信息为准。在填报涉及其他成员公司员工信息时，应互相保持一致。<br>5、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 成员公司董监高履职信息表 | 成员公司员工证件到期日 | 员工证件到期日。 | 1、填报员工证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。<br>3、员工信息应与本公司填报的A0306<成员公司管理人员信息表>中信息保持一致。<br>4、在填报涉及集团公司员工信息时，以A0204<员工信息表>或A0206<董监高履职信息表>中相应信息为准。在填报涉及其他成员公司员工信息时，应互相保持一致。 |
| 成员公司董监高履职信息表 | 董监高类型 | 参照《业务代码表》中的“董监高类型代码”，填报代码。 | 参照《业务代码表》中的“董监高类型代码”，填报代码。 |
| 成员公司董监高履职信息表 | 批复日期 | 获得董事、监事、高管任职资格的批复日期。 | 1、填报获得董事、监事、高管任职资格的批复日期。<br>2、受到国家金融监督管理总局、中国人民银行、中国证券监督管理委员会等金融监管部门监督管理的境内成员公司，应填写批复日期。如无批复，应不填报内容。<br>3、对于发生董监高类型变更，但按照监管规定无需重新核准任职资格的情形，应填报原批复日期。 |
| 成员公司董监高履职信息表 | 批复文号 | 获得董事、监事、高管任职资格的批复文号。 | 1、填报获得董事、监事、高管任职资格的批复文号。<br>2、受到国家金融监督管理总局、中国人民银行、中国证券监督管理委员会等金融监管部门监督管理的境内成员公司，应填写批复文号。如无批复，应不填报内容。<br>3、对于发生董监高类型变更，但按照监管规定无需重新核准任职资格的情形，应填报原批复文号。 |
| 成员公司董监高履职信息表 | 公司职务 | “董监高标志”含“高管”时必填，填报所管辖部门，填写公司内部组织架构中的部门名称，如有多个需列填，以英文分号“;”分隔。 | 1、填报所管辖部门，按照公司内部组织架构中的部门名称填写。<br>2、如有多个需列填，以英文分号“;”分隔。<br>3、“董监高类型”填报高级管理人员时必填。<br>4、高管人员无任何管辖部门时，填报默认值“000000”。 |
| 成员公司董监高履职信息表 | 党内职务 | 国有银行保险机构填报董监高的党内职务。参照《业务代码表》中的“党内职务代码”，填报代码。 | 1、国有银行保险机构填报董监高的党内职务。<br>2、参照《业务代码表》中的“党内职务代码”，填报代码。<br>3、按照实际情况填报，无党内职务时不填报内容。 |
| 成员公司董监高履职信息表 | 专门委员会任职 | 填报董事参加的专门委员会名称。如有多个需列填，用“;”隔开。 | 填报董事参加的专门委员会名称。如有多个需列填，以英文分号“;”分隔。 |
| 成员公司董监高履职信息表 | 开始日期 | 填报董事、监事、高管任职开始日期。 | 1、填报董事、监事、高管实际到任履职日期。<br>2、开始日期不应早于批复日期。 |
| 成员公司董监高履职信息表 | 结束日期 | 填报董事、监事、高管离任日期，若现任职则填默认值99991231。 | 1、填报董事、监事、高管离任日期。<br>2、若尚在任职期间则填“99991231"。 |
| 成员公司董监高履职信息表 | 提名机构名称 | “董监高类型”为“董事”或“监事”时必填，填报提名机构名称。 | 1、填报提名机构名称。<br>2、“董监高类型”为“董事”或“监事”时必填。<br>3、无提名机构时填写“000000”。 |
| 成员公司董监高履职信息表 | 外部公司任职 | 填报董事、监事、高管在外部公司任职情况。外部公司任职是指在本公司以外的任职。 | 1、填报董事、监事、高管在外部公司任职情况。外部公司任职是指在本公司以外的任职。<br>2、集团领导外部任职参考集团人力部提供的《集团领导任职情况》进行填写。<br>3、同一公司不同职务间用“、”分隔，不同公司职务间以英文分号“;”分隔。 |
| 成员公司董监高履职信息表 | 履职评价结果 | “董监高标志”为“董事”或“监事”时必填，填报董事、监事、高管的最近年度履职评价结果。参照《业务代码表》中的“履职评价结果代码”，填报代码。如无评级结果，填写默认值。 | 1、填报董事、监事、高管的最近年度履职评价结果。<br>2、参照《业务代码表》中的“履职评价结果代码”，填报代码。<br>3、“董监高类型”为董事或监事时必填。<br>4、无履职评价结果时填报“000000”。 |
| 成员公司董监高履职信息表 | 评价结果报告日期 | “董监高标志”为“董事”或“监事”时必填，填报最近年度公司向监管机构报告董事监事履职情况及评价结果的日期。 | 1、填报最近年度公司向监管机构报告董事监事履职情况及评价结果的日期。<br>2、“董监高类型”为董事或监事时必填。<br>3、无履职评价结果时填报“99991231”。 |
