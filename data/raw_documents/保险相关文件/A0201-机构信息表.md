# A0201-机构信息表


---

## A0201-机构信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 机构信息表 | LEI编码 | 填报机构的全球法人识别编码（LEI），法人识别编码是按照国际标准化组织的《金融服务法人机构识别编码》（ISO17442：2012）标准为法人机构分配的由20位数字和字母组成的唯一编码，可以用于标识与国际金融交易相关联的法人机构。 | 1、填报机构的全球法人识别编码（LEI）。<br>2、法人识别编码是按照国际标准化组织的《金融服务法人机构识别编码》（ISO17442：2012）标准为法人机构分配的由20位数字和字母组成的唯一编码，可以用于标识与国际金融交易相关联的法人机构。 |
| 机构信息表 | 工商注册日期 | 以工商注册的成立日期为准。 | 1、填报集团公司营业执照上的成立日期.<br>2、当发生统一社会信用代码变更时，需要更新“工商注册日期”。 |
| 机构信息表 | 批复日期 | 填报保险集团（控股）公司开业批复文件的日期。 | 填报监管下发集团公司开业批复文件的日期。 |
| 机构信息表 | 批复文号 | 填报保险集团（控股）公司开业批复文件的文号。 | 填报监管下发集团公司开业批复文件的文号。 |
| 机构信息表 | 经营范围 | 应与工商注册中的经营范围一致。 | 1、填报集团公司工商注册中的经营范围。<br>2、如果超过该数据项的最大长度，需自行进行截取。 |
| 机构信息表 | 注册资本 | 应与工商注册中的注册资本一致。若注册资本存在外币的情况，公司应自行换算成人民币进行填报。单位：元。 | 1、填报集团公司工商注册中的注册资本。<br>2、若注册资本存在外币的情况，应自行换算成人民币进行填报。单位：元。 |
| 机构信息表 | 注册地区 | 参照《业务代码表》中的“行政区划代码”，填报代码。 | 参照《业务代码表》中的“行政区划代码”，填报代码。 |
| 机构信息表 | 注册地址 | 按照工商注册信息中的注册地填报。 | 1、填报集团公司工商注册中的注册地。<br>2、应与“国家企业信用信息公示系统”中信息一致。 |
| 机构信息表 | 是否有分支机构 | 参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、参照《业务代码表》中的“是否判断代码”，填报代码。<br>2、分支机构需有独立统一社会信用代码，办事处等不属于分支机构。 |
| 机构信息表 | 法定代表人法定名称 | 填写法定代表人姓名，应与工商注册的姓名一致。 | 填报集团公司工商注册中的法定代表人姓名。 |
| 机构信息表 | 法定代表人证件类型 | 法定代表人证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报集团公司法定代表人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。<br>3、需与“法定代表人证件号码”对应类型一致。 |
| 机构信息表 | 法定代表人证件号码 | 法定代表人证件号码。隐私，保险集团（控股）公司变形。 | 1、填报集团公司法定代表人有效证件号码。<br>2、若法定代表人为中华人民共和国公民，优先填居民身份证。<br>3、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 机构信息表 | 法定代表人证件到期日 | 法定代表人证件到期日。 | 1、填报集团公司法定代表人证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 机构信息表 | 是否有实际控制人 | 实际控制人指通过投资关系、协议或者其他安排，能够实际支配公司行为的人。参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、参照《业务代码表》中的“是否判断代码”，填报代码。<br>2、实际控制人指通过投资关系、协议或者其他安排，能够实际支配公司行为的人。 |
| 机构信息表 | 实际控制人类型 | 参照《业务代码表》中的“实际控制人类型代码”，填报代码。 | 1、填报集团公司实际控制人类型。<br>2、参照《业务代码表》中的“实际控制人类型代码”，填报代码。<br>3、“是否有实际控制人”填报“01”时必填。 |
| 机构信息表 | 实际控制人法定名称 | “是否有实际控制人”为“是”时必填。填报实际控制人名称。 | 1、填报集团公司实际控制人名称。<br>2、“是否有实际控制人”填报“01”时必填。 |
| 机构信息表 | 实际控制人证件类型 | “是否有实际控制人”为“是”时必填。填报实际控制人证件类型。对自然人，优先选填控制人居民身份证；对机构，优先选填统一社会信用代码。参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报集团公司实际控制人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。<br>3、“是否有实际控制人”填报“01”时必填。<br>4、需与“实际控制人证件号码”对应类型一致。 |
| 机构信息表 | 实际控制人证件号码 | “是否有实际控制人”为“是”时必填。填报有效证件号码。若为自然人证件号码，隐私，保险集团（控股）公司变形。 | 1、填报集团公司实际控制人有效证件号码。<br>2、“是否有实际控制人”填报“01”时必填。<br>3、实际控制人为自然人，填报自然人证件号码，若实际控制人为中华人民共和国公民，优先填居民身份证；实际控制人为境内机构时填写统一社会信用代码，实际控制人为境外机构时填写企业注册码、税务号等有效代码。<br>4、若为自然人证件号码，按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 机构信息表 | 实际控制人证件到期日 | 实际控制人证件到期日。 | 1、填报集团公司实际控制人证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 机构信息表 | 许可证发放日期 | 保险许可证号的发放日期。 | 填报保险许可证最近一次发证日期。 |
| 机构信息表 | 许可证注销日期 | 保险许可证号的注销日期，如未注销，填写默认值99991231。 | 填报注销保险许可证号的退出日期。如未注销，填报默认值“99991231”。 |
