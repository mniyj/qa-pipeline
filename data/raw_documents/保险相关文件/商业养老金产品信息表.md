| 商业养老金产品信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 商业养老金产品信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 商业养老金产品信息表 | 产品代码 | 1、保险公司自行定义的商业养老金产品代码，应在机构范围内具有唯一性。 |  |
| 商业养老金产品信息表 | 产品名称 | 1、产品的中文全称，应与向保险业监督管理机构报备的名称保持一致。 |  |

| 商业养老金产品信息表 | 产品条款备案编码 | 1、条款在报送保险业监督管理机构审批或备案时的文字编码。格式为：“公司简称”＋“〔报送年度〕”＋“产品类别”＋“本年度公司报送保险业监督管理机构审批或备案的商业养老金产品条款总序号”。如“XX养老〔20XX〕商业养老金001号”。 |  |

| 商业养老金产品信息表 | 在售标志 | 1、截至采集日期，该产品是否在售。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 |  |
| 商业养老金产品信息表 | 产品成立日期 | 1、填报产品资金的实际投资运作起始日。 |  |

| 商业养老金产品信息表 | 产品停售日期 | 1、填报产品的实际停售日期。当“在售标志”为“0”时必填。 |  |
| 商业养老金产品信息表 | 风险等级 | 1、指依据产品投资策略、范围、比例等确定的产品风险水平。<br>2、枚举值：低风险；中低风险；中等风险；中高风险；高风险；其他；不适用。 |  |
| 商业养老金产品信息表 | 产品周期 | 1、指每笔保费的持有周期。 |  |
| 商业养老金产品信息表 | 产品周期单位 | 1、指每笔保费持有周期的计量单位。<br>2、枚举值：年；月；日。 |  |
| 商业养老金产品信息表 | 目标日期 | 1、当“产品类型”为“混合类-目标日期”时，必填。填报产品合同条款约定的目标日期。 |  |
| 商业养老金产品信息表 | 保本周期 | 1、当“产品类型”为“混合类-期限保本”时，必填。填报产品合同条款约定的保本核算周期。 |  |
| 商业养老金产品信息表 | 保本周期单位 | 1、当“产品类型”为“混合类-期限保本”时，必填。填报保本核算周期对应的计量单位。<br>2、枚举值：年；月；日。 |  |
| 商业养老金产品信息表 | 最低投保年龄 | 1、产品的最低投保年龄。以周岁记，小于1周岁或无最低投保年龄限制，填报0。 |  |
| 商业养老金产品信息表 | 最高投保年龄 | 1、产品的最高投保年龄。以周岁记，最高投保年龄为法定退休年龄，填报800；无最高可投保年龄限制，填报900。 |  |
| 商业养老金产品信息表 | 产品管理费费率 | 1、填报备案费率，若为分段费率，以文字说明不同条件下的各费率期间。 |  |
| 商业养老金产品信息表 | 产品退出费费率 | 1、填报备案费率，若为分段费率，以文字说明不同条件下的各费率期间。示例：非保本核算周期期满日，赎回费率1%，保本核算周期期满日退出费率0%。 |  |
| 商业养老金产品信息表 | 销售地区 | 1、可销售本产品的地区。如涉及多个，以英文半角分号分隔填报。<br>示例：北京；上海。<br>2、参照《业务代码表》“销售地区代码”，编号CD000054。 |  |

| 商业养老金产品信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
