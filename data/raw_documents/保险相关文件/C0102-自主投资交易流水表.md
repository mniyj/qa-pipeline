# C0102-自主投资交易流水表


---

## C0102-自主投资交易流水表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 自主投资交易流水表 | 账户名称 | 机构投资账户名称，应具有唯一标识。 | 1、填报机构投资账户名称，应具有唯一标识。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 账户代码 | 机构投资账户代码，应具有唯一标识。 | 1、填报机构投资账户代码，应具有唯一标识。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 交易编号 | 公司自行定义的交易编号，在同一账户下应具有唯一标识。 | 1、填报公司自行定义的交易编号，在同一账户下应具有唯一标识。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 资产类型 | 参照《业务代码表》中的“资产负债统计科目代码”，填报代码。 | 参照《业务代码表》中的“资产负债统计科目代码”，填报代码。 |
| 自主投资交易流水表 | 资产名称 | 有公开市场的资产填写公开市场资产名称，或填写合同上的资产名称。 | 1、有公开市场的资产填报公开市场资产名称，或填报合同上的资产名称。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 资产代码 | 有公开市场代码的资产填写公开市场代码，无公开市场代码的资产需要机构自定义代码。 | 1、有公开市场代码的资产填报公开市场代码，无公开市场代码的资产需要机构自定义代码。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 交易对手法定名称 | 交易对手名称，包括中央对手方。 | 1、填报交易对手名称，包括中央对手方。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 交易对手证件类型 | 交易对手证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。 | 交易对手证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。 |
| 自主投资交易流水表 | 交易对手证件号码 | 交易对手证件号码。 | 1、填报交易对手证件号码。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 交易对手证件到期日 | 交易对手证件到期日。 | 1、填报交易对手证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 自主投资交易流水表 | 交易对手LEI编码 | 填写交易对手全球法人识别编码。 | 1、填报交易对手全球法人识别编码。<br>2、LEI是按照国际标准化组织ISO 17442标准为全球法人分配的唯一识别编码，LEI编码是由20位数字和字母组成的唯一编码。我国LEI编码包括前缀码部分、预留位部分、机构特定部分和校验位四部分。 |
| 自主投资交易流水表 | 交易币种 | 参照《业务代码表》中的“币种代码”，填报代码。 | 参照《业务代码表》中的“币种代码”，填报代码。 |
| 自主投资交易流水表 | 交易市场类型 | 参照《业务代码表》中的“交易市场类型代码”，填报代码。 | 参照《业务代码表》中的“交易市场类型代码”，填报代码。 |
| 自主投资交易流水表 | 交易日期 | 交易行为发生日期。格式：YYYYMMDD。 | 1、按照YYYYMMD格式填报交易行为发生日期。<br>2、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 交易摘要 | 交易情况描述。 | 填报交易情况描述。 |
| 自主投资交易流水表 | 资金流向 | 参照《业务代码表》中的“资金流向代码”，填报代码。 | 参照《业务代码表》中的“资金流向代码”，填报代码。 |
| 自主投资交易流水表 | 交易币成交金额 | 买卖资产的成交金额。 | 填报买卖资产的成交金额。 |
| 自主投资交易流水表 | 交易币结算金额 | 资产最终结算的金额，以实际收付金额为准。 | 填报资产最终结算的金额，以实际收付金额为准。 |
| 自主投资交易流水表 | 本位币成交金额 | 买卖资产的成交金额。单位：元。 | 1、填报买卖资产的成交金额。<br>2、单位：元。 |
| 自主投资交易流水表 | 本位币结算金额 | 资产最终结算的金额，以实际收付金额为准。单位：元。 | 1、填报资产最终结算的金额，以实际收付金额为准。<br>2、单位：元。 |
| 自主投资交易流水表 | 银行账户号码 | 本笔交易对应的银行账号。需与保险集团（控股）公司银行账户信息表中的银行账户号码匹配。<br>如是通过第三方支付交易，填报本笔交易所对应的第三方支付账号关联银行账号，并在备注项内填报第三方支付信息。 | 1、填报本笔交易对应的银行账号。<br>2、如是通过第三方支付交易，填报本笔交易所对应的第三方支付账号关联银行账号，并在备注项内填报第三方支付信息。<br>3、不可填报集团EAST规范默认值或其他无效数据。<br>4、需与B0204<银行账户信息表>中的”银行账户号码”匹配。 |
| 自主投资交易流水表 | 交易对手银行法定名称 | 交易对手银行开户行名称。如是场内交易，填报本机构关联交易所名称，如果交易对手通过第三方支付机构交易，则填报第三方支付机构法定名称。 | 1、填报交易对手银行开户行名称。<br>2、如是场内交易，填报本机构关联交易所名称，如果交易对手通过第三方支付机构交易，则填报第三方支付机构法定名称。<br>3、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 交易对手银行证件类型 | 交易对手银行证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。<br>如果是第三方支付机构，则填报第三方支付机构经营许可证件类型。 | 1、填报交易对手银行证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。<br>3、如果是第三方支付机构，则填报第三方支付机构经营许可证件类型。 |
| 自主投资交易流水表 | 交易对手银行证件号码 | 交易对手银行证件号码。如果交易对手通过第三方支付机构交易，则填报第三方支付机构经营许可证件号码。 | 1、填报交易对手银行证件号码。<br>2、如果交易对手通过第三方支付机构交易，则填报第三方支付机构经营许可证件号码。<br>3、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 交易对手银行证件到期日 | 交易对手银行证件到期日。<br>如果交易对手通过第三方支付机构交易，则填报第三方支付机构经营许可证件到期日。 | 1、填报交易对手银行证件到期日。<br>2、如果交易对手通过第三方支付机构交易，则填报第三方支付机构经营许可证件到期日。<br>3、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 自主投资交易流水表 | 交易对手银行账户号码 | 交易对手银行账户号码。如是场内交易，填报本机构关联交易所的账户号码。如果交易对手通过第三方支付机构交易，则填报交易对手在第三方支付机构的账户号码。 | 1、填报交易对手银行账户号码。<br>2、如是场内交易，填报本机构关联交易所的账户号码。如果交易对手通过第三方支付机构交易，则填报交易对手在第三方支付机构的账户号码。<br>3、不可填报集团EAST规范默认值或其他无效数据。 |
| 自主投资交易流水表 | 备注 | 补充说明情况。 | 填报补充说明情况。 |
