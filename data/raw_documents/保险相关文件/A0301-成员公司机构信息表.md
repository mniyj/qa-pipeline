# A0301-成员公司机构信息表


---

## A0301-成员公司机构信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 成员公司机构信息表 | 成员公司机构类型 | 参照《业务代码表》中的“机构类型代码”，填报代码。 | 1、填写成员公司本体的机构类型。<br>1、参照《业务代码表》中的“机构类型代码”，填报代码。<br>2、未受到国家金融监督管理总局、中国人民银行、中国证券监督管理委员会等金融监管部门监督管理的境内成员公司，填报“7030000”非金融机构法人。 |
| 成员公司机构信息表 | 成员公司LEI编码 | 填报成员公司的全球法人识别编码（LEI），法人识别编码是按照国际标准化组织的《金融服务法人机构识别编码》（ISO17442：2012）标准为法人机构分配的由20位数字和字母组成的唯一编码，可以用于标识与国际金融交易相关联的法人机构。 | 1、填报成员公司的全球法人识别编码（LEI）。<br>2、法人识别编码是按照国际标准化组织的《金融服务法人机构识别编码》（ISO17442：2012）标准为法人机构分配的由20位数字和字母组成的唯一编码，可以用于标识与国际金融交易相关联的法人机构。 |
| 成员公司机构信息表 | 工商注册日期 | 以工商注册的成立日期为准。 | 1、填报工商注册的成立日期。<br>2、境内成员公司填报营业执照上的成立日期，境外成员公司填报本机构注册成立的日期。<br>3、当“成员公司统一社会信用代码”发生变更时，需要更新“工商注册日期”。 |
| 成员公司机构信息表 | 批复日期 | 填报成员公司中保险机构开业批复文件的日期。 | 1、保险机构成员公司填报监管机构对总公司下发开业批复文件的日期。<br>2、非保险机构成员公司不填报内容。 |
| 成员公司机构信息表 | 批复文号 | 填报成员公司中保险机构开业批复文件的文号。 | 1、保险机构成员公司填报监管机构对总公司下发开业批复文件的文号。<br>2、非保险机构成员公司不填报内容。 |
| 成员公司机构信息表 | 经营范围 | 应与工商注册中的经营范围一致。 | 1、填报成员公司工商注册中的经营范围。<br>2、如果超过该数据项的最大长度，需自行进行截取。<br>3、境内成员公司应与“国家企业信用信息公示系统”中信息一致，境外成员公司涉及外文时应转换成中文后报送。 |
| 成员公司机构信息表 | 注册资本 | 应与工商注册中的注册资本一致。若注册资本存在外币的情况，公司应自行换算成人民币进行填报。单位：元。 | 1、填报成员公司工商注册中的注册资本。<br>2、若注册资本存在外币的情况，应自行换算成人民币进行填报。单位：元。 |
| 成员公司机构信息表 | 注册地区 | 参照《业务代码表》中的“行政区划代码”，填报代码。 | 参照《业务代码表》中的“行政区划代码”，填报代码。 |
| 成员公司机构信息表 | 注册地址 | 按照工商注册信息中的注册地填报。 | 1、填报成员公司工商注册中的注册地。<br>2、境内成员公司应与“国家企业信用信息公示系统”中信息一致，境外成员公司涉及外文时应转换成中文后报送。 |
| 成员公司机构信息表 | 是否有分支机构 | 参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、参照《业务代码表》中的“是否判断代码”，填报代码。<br>2、分支机构需有独立统一社会信用代码，办事处等不属于分支机构。 |
| 成员公司机构信息表 | 管理模式 | 填报保险集团（控股）公司对该成员公司的管理模式。参照《业务代码表》中的“管理模式代码”，填报代码。 | 1、填报保险集团（控股）公司对该成员公司的管理模式。<br>2、参照《业务代码表》中的“管理模式代码”，填报代码。 |
| 成员公司机构信息表 | 行业类型 | 按成员公司所从事的生产经营活动或其他社会经济活动的性质进行行业分类，参照《业务代码表》中的“行业类型代码”，填报代码。 | 1、按成员公司所从事的生产经营活动或其他社会经济活动的性质填报行业分类。<br>2、参照《业务代码表》中的“行业类型代码”，填报代码。<br>3、应与报送统计局等其他监管机构的口径一致。 |
| 成员公司机构信息表 | 法定代表人法定名称 | 填写法定代表人姓名，应与工商注册的姓名一致。如无法定代表人，则填写“不适用”。 | 1、填报成员公司工商注册中的法定代表人姓名。<br>3、如无法定代表人，则填写“不适用”。 |
| 成员公司机构信息表 | 法定代表人证件类型 | 法定代表人证件类型，参照《业务代码表》中的“证件类型代码”，填报代码。如无法定代表人，则选择“其他证件（个人）”。 | 1、填报法定代表人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。<br>3、如无法定代表人，则填报“1999”其他证件（个人）。<br>4、需与“法定代表人证件号码”对应类型一致。 |
| 成员公司机构信息表 | 法定代表人证件号码 | 法定代表人证件号码。隐私，保险集团（控股）公司变形。如无法定代表人，则填写9999。 | 1、填报法定代表人证件号码。<br>2、如无法定代表人，则填报“9999”。<br>3、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 成员公司机构信息表 | 法定代表人证件到期日 | 法定代表人证件到期日。如无法定代表人，则填写99991231。 | 1、填报法定代表人证件到期日。如无法定代表人，则填报“99991231”。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 成员公司机构信息表 | 是否有实际控制人 | 实际控制人指通过投资关系、协议或者其他安排，能够实际支配公司行为的人。参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、参照《业务代码表》中的“是否判断代码”，填报代码。<br>2、实际控制人指通过投资关系、协议或者其他安排，能够实际支配公司行为的人。 |
| 成员公司机构信息表 | 实际控制人类型 | 参照《业务代码表》中的“实际控制人类型代码”，填报代码。 | 1、参照《业务代码表》中的“实际控制人类型代码”，填报代码。<br>2、“是否有实际控制人”填报“01”时必填。<br>3、不同机构填报同一实际控制人时，“实际控制人类型”应保持一致。 |
| 成员公司机构信息表 | 实际控制人法定名称 | “是否有实际控制人”为“是”时必填。填报实际控制人名称。 | 1、填报实际控制人名称。<br>2、“是否有实际控制人”填报“01”时必填。<br>3、填报涉及集团公司信息时，应与A0201<机构信息表>中的机构信息保持一致；填报涉及其他成员公司信息时，应与实际控制公司填报A0301<成员公司机构信息表>中相应信息为准。 |
| 成员公司机构信息表 | 实际控制人证件类型 | “是否有实际控制人”为“是”时必填。填报实际控制人证件类型。对自然人，优先选填控制人居民身份证；对机构，优先选填统一社会信用代码。参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、填报实际控制人证件类型。<br>2、参照《业务代码表》中的“证件类型代码”，填报代码。<br>3、“是否有实际控制人”填报“01”时必填。<br>4、需与“实际控制人证件号码”对应类型一致。<br>5、填报涉及集团公司信息时，应与A0201<机构信息表>中的机构信息保持一致；填报涉及其他成员公司信息时，应与实际控制公司填报A0301<成员公司机构信息表>中相应信息为准。 |
| 成员公司机构信息表 | 实际控制人证件号码 | “是否有实际控制人”为“是”时必填。填报有效证件号码。若为自然人证件号码，隐私，保险集团（控股）公司变形。 | 1、填报实际控制人有效证件号码。<br>2、“是否有实际控制人”填报“01”时必填。<br>3、实际控制人为自然人，填报自然人证件号码，若实际控制人为中华人民共和国公民，优先填居民身份证；实际控制人为境内机构时填写统一社会信用代码，实际控制人为境外机构时填写企业注册码、税务号等有效代码。<br>4、填报涉及集团公司信息时，应与A0201<机构信息表>中的机构信息保持一致；填报涉及其他成员公司信息时，应与实际控制公司填报A0301<成员公司机构信息表>中相应信息为准。<br>5、若为自然人证件号码，按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 成员公司机构信息表 | 实际控制人证件到期日 | 实际控制人证件到期日。 | 1、填报实际控制人证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。<br>3、填报涉及集团公司信息时，应与A0201<机构信息表>中的机构信息保持一致；填报涉及其他成员公司信息时，应与实际控制公司填报A0301<成员公司机构信息表>中相应信息为准。 |
| 成员公司机构信息表 | 许可证发放日期 | 保险许可证号的发放日期。 | 1、填报保险许可证、保险中介许可证最近一次发证日期。<br>2、非保险机构填报“99991231”。 |
| 成员公司机构信息表 | 许可证注销日期 | 保险许可证号的注销日期，如未注销，填写默认值99991231。 | 1、填报注销保险许可证、保险中介许可证号的退出日期。如未注销，填写默认值“99991231”。<br>2、非保险机构填报“99991231”。 |
