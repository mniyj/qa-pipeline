| 存款证实书信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 存款证实书信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 存款证实书信息表 | 投资账户名称 | 1、机构投资账户名称。 |  |
| 存款证实书信息表 | 投资账户代码 | 1、机构投资账户代码，应具有唯一性。关联数据项：投资账户信息表-投资账户代码。 |  |
| 存款证实书信息表 | 资产代码 | 1、机构自定义的资产代码，应在机构范围内具有唯一性。关联数据项：自主投资持仓表-资产代码。 |  |
| 存款证实书信息表 | 存款证实书编号 | 1、存款银行给出的存款证实书编号，包括“NO.”“浙”“（03）”等字样，如无存款证实书编号，优先填列业务编号或账号。 |  |
| 存款证实书信息表 | 存款证实书全称 | 1、存款银行名称+起息年份+存款类型。 |  |
| 存款证实书信息表 | 存款类型 | 1、存款的具体类型。<br>2、枚举值：定期存款；协议存款；结构性存款；同业存款；大额存款；通知存款。 |  |
| 存款证实书信息表 | 存款币种 | 1、存款所对应的货币币种。<br>2、参照《业务代码表》“币种代码”，编号CD000009。 |  |

| 存款证实书信息表 | 存款银行证件类型 | 1、存款银行证件类型，填报代码。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 存款证实书信息表 | 存款银行证件类型中文名称 | 1、存款银行证件类型，填报中文名称。<br>2、参照《业务代码表》“证件类型代码”，编号CD000005。 |  |
| 存款证实书信息表 | 存款银行证件号码 | 1、存款银行证件号码。 |  |
| 存款证实书信息表 | 存款银行证件到期日 | 1、存款银行证件到期日。 |  |
| 存款证实书信息表 | 存款银行LEI编码 | 1、填写存款银行全球法人识别编码。 |  |
| 存款证实书信息表 | 存款银行所在地 | 1、存款银行所在行政区划。除以下情况及其他可能存在的特例外，应填报省市县三级完整行政区划的名称：<br>（1）相关地区位于直辖市，如北京市海淀区；<br>（2）相关地区位于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县；<br>（3）相关地区位于未下设区县的市，如广东省东莞市、海南省儋州市；<br>（4）相关地区位于港澳台地区，如香港特别行政区。<br>如为除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 存款证实书信息表 | 存款银行外部信用评级 | 1、填写存款银行最新外部信用评级结果。当存在多个外部信用评级结果时，应参照《中国保监会关于印发<保险公司偿付能力报告编制规则——问题解答第15号：信用风险评估方法和信用评级>等5项问题解答的通知》（保监发〔2013〕24号）要求，按如下规定处理：<br>（一）境内银行的信用评级原则上应当按照境内评级机构的评级结果确定，境外银行的信用评级原则上应当按照国际公认评级机构的评级结果确定。<br>（二）有一家以上符合要求的评级机构给予评级的，从低适用。<br>（三）采用最近一期符合要求的评级结果。<br>2、参照《业务代码表》“信用评级等级代码”，编号CD000039。 |  |

| 存款证实书信息表 | 利率类型 | 1、存款利率类型。<br>2、枚举值：浮动；固定；结构化；其他。 |  |
| 存款证实书信息表 | 存款利率 | 1、利率为直接按小数形式填写，保留小数点后6位。非固定利率以当前节点利率填写。 |  |
| 存款证实书信息表 | 计息基准 | 1、存款计息基准。<br>2、枚举值：实际/365；实际/实际；实际/360；30/360。 |  |
| 存款证实书信息表 | 基准利率 | 1、基准利率的类型，“利率类型”为“浮动”时必填。<br>2、参照《业务代码表》“基准利率代码”，编号CD000050。 |  |
| 存款证实书信息表 | 利差 | 1、“利率类型”为“浮动”时为必填。利差点数，可以为正数、零或负数，不含%，如：填50代表50BP表示0.50%。 |  |
| 存款证实书信息表 | 利率描述 | 1、当“利率类型”“存款利率”“计息基准”“基准利率”“利差”等数据项无法完全体现计息结构时，此项填写具体情况。如前述字段能够体现计息结构，可选填“无”。 |  |
| 存款证实书信息表 | 年付息频率 | 1、存款证实书的付息频率。<br>2、枚举值：到期一次还本付息；年；半年；季；月。 |  |

| 存款证实书信息表 | 质押用途 | 1、当“质押标志”为“1”时，必填。<br>2、枚举值：融资；担保；委托贷款。 |  |
| 存款证实书信息表 | 备注 | 1、填写其他需要报送的但是目前无法标准化的信息。 |  |
