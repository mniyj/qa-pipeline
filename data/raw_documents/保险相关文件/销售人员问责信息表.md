# 销售人员问责信息表


---

人身保险公司（2024版）销售人员问责信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 销售人员问责信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 销售人员问责信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 销售人员问责信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 销售人员问责信息表 | 所属内部机构号 | 1、该销售人员当前实际管理机构的内部机构号（最细粒度）。若截至问责日期，该销售人员已离职或退休，填报该销售人员离职或退休前的所属内部机构号。关联数据项：分支机构信息表-内部机构号。 | 1、若员工所属分支机构发生变化，对于已报送的问责信息，暂不要求更新“所属内部机构号”信息。 |
| 销售人员问责信息表 | 所属机构名称 | 1、与所属内部机构号相匹配的内部机构规范全称。关联数据项：分支机构信息表-机构名称。 |  |
| 销售人员问责信息表 | 违法违规事实发生时所在机构号 | 1、被问责事件发生时该销售人员所在机构的内部机构号，填报最细粒度。如相关违法违规事实在一段期间内存续，填报事实起始日该销售人员所在机构的内部机构号。关联数据项：分支机构信息表-内部机构号。 |  |
| 销售人员问责信息表 | 违法违规事实发生时所在机构名称 | 1、与“违法违规事实发生时所在机构号”相匹配的机构名称。关联数据项：分支机构信息表-机构名称。 |  |
| 销售人员问责信息表 | 销售人员代码 | 1、保险公司分配给销售人员的工号或编号，应具有唯一性。关联数据项：销售人员信息表-销售人员代码。 |  |
| 销售人员问责信息表 | 销售人员姓名 | 1、销售人员的姓名。 |  |
| 销售人员问责信息表 | 问责编号 | 1、该条问责信息的唯一标识号，应在机构范围内唯一。 |  |
| 销售人员问责信息表 | 问责文号 | 1、填写内部问责文书对应的文号。如无，填报“不适用”。 |  |
| 销售人员问责信息表 | 问责机构 | 1、发布该问责决定的机构规范全称。 |  |
| 销售人员问责信息表 | 问责日期 | 1、填报问责文书的出具时间，或其他表明问责决定已作出的时间。 |  |
| 销售人员问责信息表 | 问责期起始日期 | 1、填报内部问责期间的开始日期。当相关问责方式或决定存在明确的起止时点时，必填。以禁止某销售人员在一定期间内晋升为例：公司作出问责决定的日期为问责日期，该销售人员禁止晋升期间的起止日期，如2021年1月1日至2021年12月31日，分别为此项问责所对应期间的开始日期与结束日期。 |  |
| 销售人员问责信息表 | 问责期结束日期 | 1、填报内部问责期间的终止日期。当相关问责方式或决定存在明确的起止时点时，必填。若相关问责覆盖终身，填报99990101。以禁止某销售人员在一定期间内晋升为例：公司作出问责决定的日期为问责日期，该销售人员禁止晋升期间的起止日期，如2021年1月1日至2021年12月31日，分别为此项问责所对应期间的开始日期与结束日期。 |  |
| 销售人员问责信息表 | 问责方式 | 1、问责方式。如涉及多个，需用半角英文分号分隔填列。<br>2、参照《业务代码表》“问责方式代码”，编号CD000063。 |  |
| 销售人员问责信息表 | 问责原因 | 1、填写问责文件列示的问责原因。主要内容为销售人员违法、违规、违纪的主要事实。 |  |
| 销售人员问责信息表 | 问责依据 | 1、填报作出此次问责的法律法规、内部规章的名称。 |  |
| 销售人员问责信息表 | 问责决定 | 1、填写问责文件列示的问责决定。 |  |
| 销售人员问责信息表 | 罚款金额 | 1、当“问责方式”包含“罚款”时，必填。填报该项问责对应的罚款金额。若截至采集日期，罚款金额尚未确定，可暂时报送“-1”，并待相关金额明确后更新报送。 | 1、对于问责方式是过扣除绩效和销售员工额外交回其他罚金的情况，罚款金额为扣减薪资金额与个人交回金额的和。如果存在分多个月进行薪资扣减的情况，“罚款金额”建议直接按照已确定的罚款总金额报送，后续若发生变化，再另行更新。无需逐期累加。 |
| 销售人员问责信息表 | 以扣减薪资方式收取罚款标志 | 1、当“罚款金额”非空时，必填。用于判别人身保险公司是否以扣减薪资的方式收取罚款。<br>2、枚举值：1；0。“1”代表是，“0”代表否。 | 1、对于问责方式是过扣除绩效和销售员工额外交回其他罚金的情况，以扣减薪资方式收取罚款标志报送“1”。 |
| 销售人员问责信息表 | 资金流水编号 | 1、当“罚款金额”非空且“以扣减薪资方式收取罚款标志”为“0”时，必填。填报受问责人员缴纳罚款时，相关资金流水在人身保险公司内部的唯一标识号。如涉及多个，以英文半角分号分隔填列；若当月尚未生成，报送“未生成”。 | 1、对于问责方式是过扣除绩效和销售员工额外交回其他罚金的情况，资金流水编号报送个人交回金额部分的流水编号。如果存在分多个月进行薪资扣减的情况，当仅扣减绩效时，“以扣减薪资方式收取罚款标志”报送“1”，“资金流水编号”为空；当扣减多期绩效后仍不足以缴纳罚款，由员工另行缴纳差额时，“以扣减薪资方式收取罚款标志”报送“1”，“资金流水编号”报送收取差额罚款的资金流水编号。 |
| 销售人员问责信息表 | 外部处罚决定书文号 | 1、填报外部处罚的文号。当内部问责与外部处罚关联时，必填。关联数据项：销售人员处罚信息表-处罚文号。若外部处罚晚于内部问责发生，应在外部处罚发生后及时更新报送。 |  |
| 销售人员问责信息表 | 内部机构所在省 | 1、该销售人员实际管理机构所对应内部机构注册地或营业场所所在省，以营业执照登记信息为准。当该机构在中国大陆及其港澳台地区注册时，填报具体省级行政区划的信息；当该机构在其他境外地区注册时，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员问责信息表 | 内部机构所在地市 | 1、该销售人员实际管理机构所对应内部机构注册地或营业场所所在地市，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）当省级行政区划为直辖市（如北京市）时，本级行政区划填报直辖市的名称。<br>（3）对于省（自治区）直辖县级行政区划，如河南省济源市、海南省定安县，本级行政区划如不适用，填报“不适用”。<br>（4）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（5）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员问责信息表 | 内部机构所在区县 | 1、该销售人员实际管理机构所对应内部机构注册地或营业场所所在区县，以营业执照登记信息为准。填报要求如下：<br>（1）如涉及历史地址信息，按照现有行政区划业务代码映射后报送。<br>（2）对于未下设区县的市，如广东省东莞市、海南省儋州市，本级行政区划如不适用，填报“不适用”。<br>（3）对于港澳台地区，本级行政区划暂时填报“不适用”。<br>（4）对于除港澳台以外的其他境外地区，填报“不适用”。<br>2、参照《业务代码表》“行政区划代码”，编号CD000013。 |  |
| 销售人员问责信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
