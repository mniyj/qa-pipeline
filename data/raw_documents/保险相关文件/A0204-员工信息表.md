# A0204-员工信息表


---

## A0204-员工信息表数据项填报说明


| 表中文名 | 数据项名称 | **监管规范** | **数据项填报说明** |
| --- | --- | --- | --- |
| 员工信息表 | 员工代码 | 保险集团（控股）公司自行定义的员工编号，具有唯一性。一般由英文字母、数字、常见字符组成。 | 1、填报集团公司自行定义的员工编号，具有唯一性。一般由英文字母、数字、常见字符组成。<br>2、员工代码不可填报证件号码或集团EAST规范默认值或其他无效数据。<br>3、报送的所有期次A0204<员工信息表>、A0203<机构处罚信息表>、A0205<员工问责信息表>、A0206<董监高履职信息表>、A0207<董监高处罚信息表>中，员工与员工代码保持一一对应的关系。 |
| 员工信息表 | 员工法定名称 | 员工有效身份证件上的姓名。隐私，保险集团（控股）公司变形。 | 1、填报员工有效身份证件上的姓名。<br>2、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 员工信息表 | 员工证件类型 | 参照《业务代码表》中的“证件类型代码”，填报代码。 | 1、参照《业务代码表》中的“证件类型代码”，填报代码。<br>2、需与“员工证件号码”对应类型一致。 |
| 员工信息表 | 员工证件号码 | 身份证号、护照号等有效证件号码，隐私，保险集团（控股）公司变形。 | 1、填报身份证号、护照号等有效证件号码。<br>2、员工为中华人民共和国公民时，优先填居民身份证。<br>3、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 员工信息表 | 员工证件到期日 | 员工证件到期日。 | 1、填报员工证件到期日。<br>2、对于长期有效证件应填报“99991231”；如果公司不掌握到期日信息，不填报内容。 |
| 员工信息表 | 性别 | 参照《业务代码表》中的“性别代码”，填报代码。 | 参照《业务代码表》中的“性别代码”，填报代码。 |
| 员工信息表 | 民族 | 员工的民族。国家认可的在公安户籍管理部门正式登记注册的客户所属民族。参照《业务代码表》中的“民族代码”，填报代码。 | 1、填报员工的民族。国家认可的在公安户籍管理部门正式登记注册的客户所属民族。<br>2、参照《业务代码表》中的“民族代码”，填报代码。<br>3、非中华人民共和国公民应填报“99”。 |
| 员工信息表 | 出生日期 | 员工出生日期。隐私，暂不取。保险集团（控股）公司需在本地保留原文数据，并报送99991231。 | 1、填报员工出生日期。<br>2、不可填报集团EAST规范默认值或其他无效数据。<br>3、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 员工信息表 | 政治面貌 | 保险集团（控股）公司员工的政治面貌。参照《业务代码表》中的“政治面貌代码”，填报代码。 | 1、填报员工的政治面貌。<br>2、参照《业务代码表》中的“政治面貌代码”，填报代码。<br>3、对于存在多个党籍的情形，优先填报“01”中国共产党党员；对于存在多个民主党派党籍的情形，应填报主要参与活动的党派。 |
| 员工信息表 | 参加政党日期 | 参加政党的日期。YYYYMM，默认值999912。 | 1、填报员工参加政党的日期，按照YYYYMM格式填报。<br>2、若“政治面貌”填报“13”群众时，该数据项填报默认值“999912”。 |
| 员工信息表 | 员工状态 | 参照《业务代码表》中的“员工状态代码”，填报代码。 | 1、填报员工在采集日期时点的最终状态。<br>2、参照《业务代码表》中的“员工状态代码”，填报代码。 |
| 员工信息表 | 员工编制 | 参照《业务代码表》中的“员工编制代码”，填报代码。员工编制正式与非正式按是否签订劳动合同来确定。 | 1、填报员工在采集日期时点的编制情况。<br>2、参照《业务代码表》中的“员工编制代码”，填报代码。<br>3、员工编制正式与非正式按是否签订劳动合同来确定。 |
| 员工信息表 | 联系电话 | 员工联系电话，区号-座机电话/手机。隐私，暂不取。保险集团（控股）公司需在本地保留原文数据，并报送“隐私”。 | 1、填报员工联系电话，联系电话包括区号-座机电话或手机。<br>2、按实际信息填写，隐私信息报出前由集团公司统一加密。 |
| 员工信息表 | 学历 | 员工学历，参照《业务代码表》中的“学历代码”，填报代码。 | 1、填报员工学历。<br>2、参照《业务代码表》中的“学历代码”，填报代码。<br>3、按照实际情况应填报至最细类别。 |
| 员工信息表 | 董监高标志 | 参照《业务代码表》中的“是否判断代码”，填报代码。 | 1、参照《业务代码表》中的“是否判断代码”，填报代码。<br>2、“董监高标志”填报“01”的人员，当期A0206<董监高履职信息表>中也需填报；“董监高标志”填报“02”的人员，当期A0206<董监高履职信息表>中不能填报。 |
| 员工信息表 | 所属部门 | “董监高标志”为“否”时必填。按公司内部规定名称填写。 | 1、按公司内部规定名称填写。<br>2、“董监高标志”填报“02”时必填。 |
| 员工信息表 | 岗位名称 | “董监高标志”为“否”时必填。按公司内部规定名称填写。 | 1、按公司内部规定名称填写。<br>2、“董监高标志”填报“02”时必填。 |
| 员工信息表 | 入司日期 | “董监高标志”为“否”时必填。则填报最近一次签订劳动合同的日期，其他人员则填报任职开始日期。 | 1、非董监高人员填报最近一次签订劳动合同的日期，董监高人员填报任职开始日期。<br>2、同一个报送期次下，“董监高标志”填报“01”的人员，“入司日期”字段填写为A0206<董监高履职信息表>中“开始日期”最早值。 |
| 员工信息表 | 离司日期 | 如董监高标志为员工，则填报离司日期，其他人员则填报任职结束日期，若未离司或仍在任职期则填默认值99991231。 | 1、“董监高标志”填报“02”时，应填报离司日期；“董监高标志”填报“01”，应填报任职结束日期。<br>2、若未离司或仍在任职期则填报默认值“99991231”。 |
