# 内部科目对照表


---

人身保险公司（2024版）内部科目对照表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 内部科目对照表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 内部科目对照表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 内部科目对照表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 内部科目对照表 | 总账会计科目编号 | 1、保险公司内部使用的科目编码，报送至最末级所有科目。 |  |
| 内部科目对照表 | 总账会计科目名称 | 1、保险公司内部使用的科目名称。 |  |
| 内部科目对照表 | 会计科目级次 | 1、总账会计科目在科目结构中所对应的级次，填报中文描述。未设置科目层级默认一级科目。<br>2、枚举值：一级科目；二级科目；三级科目；四级科目；五级科目；六级科目。 |  |
| 内部科目对照表 | 上级科目编号 | 1、填报会计科目归属的上级科目，一级科目的上级科目编号为0。 |  |
| 内部科目对照表 | 上级科目名称 | 1、填报会计科目归属的上级科目名称，一级科目的上级科目名称填写为“空”字。 |  |
| 内部科目对照表 | 会计科目类型 | 1、总账会计科目分类，填报中文描述。<br>2、枚举值：资产；负债；所有者权益；损益；资产负债共同类；表外；其他。 |  |
| 内部科目对照表 | 会计科目状态 | 1、截至采集日期，该科目的使用状态。<br>2、枚举值：使用中；已停用。 | 1、对于各账套存在共用科目的情况，如果科目在部分账套已停用，但其他账套尚在使用，仅当科目在所有账套中均停用时，再将“会计科目状态”置为“已停用”。 |
| 内部科目对照表 | 科目停用日期 | 1、当“科目状态”为“已停用”时，必填。填报该科目的停用日期。 |  |
| 内部科目对照表 | 会计期间 | 1、科目对照关系适用的会计期间。 |  |
| 内部科目对照表 | 时间周期 | 1、科目对照关系适用的报表频率。月度数据报送04，年度审定数据报送01。 |  |
| 内部科目对照表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
