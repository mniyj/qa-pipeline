# 决策议事会议信息表


---

人身保险公司（2024版）决策议事会议信息表


| 表中文名 | 数据项名称 | 数据项说明 | 银保信问答补充 |
| --- | --- | --- | --- |
| 决策议事会议信息表 | 流水号 | 1、保险机构代码+日期（YYYYMMDD）+10位流水，流水号是每天的流水号，每天都是从‘0000000001’开始。其中日期为上报数据时当前的系统日期。 |  |
| 决策议事会议信息表 | 保险机构代码 | 1、人身保险公司总公司机构代码。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 决策议事会议信息表 | 保险机构名称 | 1、人身保险公司总公司规范全称，应与保险许可证上登记的名称保持一致。<br>2、参照《业务代码表》“保险机构代码”，编号CD000002。 |  |
| 决策议事会议信息表 | 会议编号 | 1、保险公司自行编码，保证唯一性。 |  |
| 决策议事会议信息表 | 会议类型 | 1、召开的会议类型，填报中文描述。<br>2、枚举值：股东会；会员代表大会；董事会；监事会。 |  |
| 决策议事会议信息表 | 会议名称 | 1、会议的全称。 |  |
| 决策议事会议信息表 | 召开日期 | 1、会议召开的日期。 |  |
| 决策议事会议信息表 | 召开地点 | 1、会议召开的地点。如为线上会议，填报“线上会议”。 | 1、对于董事会会议的书面传签形式，不涉及召开地点，可填报书面传签。 |
| 决策议事会议信息表 | 参会人员 | 1、实际参加会议（含出席与列席）的人员姓名，使用英文半角分号隔开。如该会议包含多个议题，且不同的议题参会人员不尽相同，填报会议的总参会人员即可。 | 1、受托出席可视为出席。<br>2、对于股东会类别，按照“受托参会人员名称（代委托人名称）”报送。 |
| 决策议事会议信息表 | 出席比例 | 1、出席比例 = 实际出席人数 / 应出席人数。 |  |
| 决策议事会议信息表 | 议题序号 | 1、该会议下不同议题的序号。例如某会议下包含10个议题，序号应从1到10递增。 |  |
| 决策议事会议信息表 | 议题名称 | 1、会议议题的名称或议案的主要内容。 |  |
| 决策议事会议信息表 | 表决结果 | 1、通过举手、投票等方式对会议议题作出表决的结果。如不涉及表决或决议，填报“不适用”。参考格式为：100%通过。 |  |
| 决策议事会议信息表 | 决议公文报送监管日期 | 1、根据《银行保险机构公司治理准则》第七条，银行保险机构应当将股东大会、董事会和监事会的会议记录和决议等文件及时报送监管机构。此处填报人身保险公司向监管机构报送相关文件的日期。 |  |
| 决策议事会议信息表 | 采集日期 | 1、指该期（批次）数据报送的期末日期，例如：按日采集的表，采集日期应为每日；按月采集的表，采集日期应为月末最后一天；以此类推。如存在特殊报送要求，应以特殊要求的截止日期为采集日期；如为数据重报等情况，应填写重报数据原归属期间的期末日期，而非重报时的日期。 |  |
